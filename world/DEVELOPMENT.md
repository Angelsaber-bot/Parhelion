# Parhelion World 开发顺序

以《幻日谷与归灯镇》《前四幻史域主线》《三域主线》《全篇主线与天空终章 V3》为开发依据。先把现有地图接成能玩完、能继续存档的主线路段。每段至少包含玩家可以主动完成的任务、可见的结果，以及返回旧地图后仍然有效的变化。

## 首轮 幻日谷序章

| 路段 | 当前实现 | 接下来要补齐 |
| --- | --- | --- |
| H00 熟悉这条路 | 生活馆新游戏起点、孟槐交付外勤单、阿舟工具车的两种操作、原工坊领枪 | 主角房间到生活馆的出门路线、旧收音机交接、归灯镇与回望桥的正式地形 |
| H01 尚未发生的求救 | 工坊电台的未来时间戳、现场核对、正面急停或侧道射销、棘爪固定、顾桥撤离并补录 | 把当前工坊灰盒迁入回望桥与前哨检修线，补 07 救下第一名工人及短战斗 |
| H02–H03 初遇与回家 | 接通外联后去镜湖见 Saber，扳绞盘或打断卡销，再西行。王国撤离完成后开回望桥侧门，等访客走过桥。 | 西岭正式入口、Saber 扶住导架的动作演出、访客抵达后的镇区服务 |

新开档从生活馆起步。已完成旧开场动作或已领枪的存档沿用原任务。阶段状态由现有存档记录，救援与外联各有独立完成条件。

## 战役路线

| 顺序 | 开发任务 | 试玩验收 |
| --- | --- | --- |
| 1 | 镜湖两种解法接 Saber 契约。日落王国沿用实地撤离，访客随后穿过回望桥侧门。 | 存档能记住契约、桥门与访客抵达。 |
| 2 | 永冬药车、黑帆登舰与出港分别结算。回谷地吃热饭，在东渡口扳道岔、射断耦合销或追至封存棚，取回信标后测试归航灯与上行电路。 | 货车必须停稳才能取货。三条路线各有停靠点，存档保留停车位置与电路结果。 |
| 3 | 京都取证后回谷地翻转校准板，选择断开执行器或打开下堤旁路。 | 显示旧监控与现场的差异，实际开启所选通路。 |
| 4 | 埃及引光、泄洪并验收试航；奥尔良卸粮、开水道、交旗、鸣钟并解除桥头炮台；秦地让工匠走过阵列，再下驻令、转阵并穿过铜闸。 | 渡船与接应队到达后才能验收。三地的交接结果分别写入存档。 |
| 5 | 塔外联检与塔顶接驳。天穹可以扳西侧旁路或打掉东侧锁销，经负荷测试与机械隔离进入承日台。击败赫利昂后交接写入臂，回望桥登记回程时间。 | 转动遮板可以反射锁定光束。第二阶段要分别击毁两座支架，三阶段分别存档。 |

设计稿对黑帆与永冬的顺序，以及秦帝陵在后三域中的位置有不同安排。后续依赖暂用天空终章 V3 的结构：王国后开放黑帆与永冬，汇合到京都；京都后开放埃及与奥尔良，随后进入秦帝陵。地图继续沿用当前连续大陆，实装前用灰盒核对入口距离与谷镇回访节奏。

## 每轮交付

1. 先实现一条可走通的主路，再加能改变行动方式的替代解法和局部回访结果。
2. 验证新增任务正常输入、关键碰撞、存档恢复和相邻旧任务的交接。通常只跑直接相关的 World 用例，再做一次正式构建。
3. 更新本地启动构建，提交到 GitHub `main`，发布现有 Pages 网站，核对三个位置使用的 World 版本。World 开发提交集中在 `world/`。

当前战役使用既有地形与交互资产，新增桥、镇区事件和天空关卡先采用可玩的灰盒。设计稿中的大型地形重做、区域首领与完整演出、更多可选探索和角色动画仍需继续制作。测试使用游戏逻辑与碰撞，画面品质和帧率需要在有 GPU 的实机上验收。
