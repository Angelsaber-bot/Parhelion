# Parhelion World 开发顺序

以《幻日谷与归灯镇》《前四幻史域主线》《三域主线》《全篇主线与天空终章 V3》为开发依据。先把现有地图接成能玩完、能继续存档的主线路段。每段至少包含玩家可以主动完成的任务、可见的结果，以及返回旧地图后仍然有效的变化。

## 首轮 幻日谷序章

| 路段 | 当前实现 | 接下来要补齐 |
| --- | --- | --- |
| H00 熟悉这条路 | 生活馆新游戏起点、孟槐交付外勤单、阿舟工具车的两种操作、原工坊领枪 | 主角房间到生活馆的出门路线、旧收音机交接、归灯镇与回望桥的正式地形 |
| H01 尚未发生的求救 | 工坊电台的未来时间戳、现场核对、正面急停或侧道射销、棘爪固定、顾桥撤离并补录 | 把当前工坊灰盒迁入回望桥与前哨检修线，补 07 救下第一名工人及短战斗 |
| H02–H03 初遇与回家 | 序章接到岚的讯号亭及现有外联任务，之后可沿现有流程西行 | 镜湖与 Saber 的首个合作事件、西岭入口、王国后带访客回镇、开启永久后门 |

新开档从生活馆起步。已完成旧开场动作或已领枪的存档沿用原任务。阶段状态由现有存档记录，救援与外联各有独立完成条件。

## 后续可玩路段

| 顺序 | 开发任务 | 试玩验收 |
| --- | --- | --- |
| 1 | 做通回望桥、前哨、镜湖、西岭；完成 H02–H03 和日落王国第一条撤离线。 | 从谷地出发能辨认归路；Saber 提供协作窗口；第一批居民回到安全线；回镇有可用的新路。 |
| 2 | 推进日落王国完整主线，再分别做永冬的分段撤退和黑帆的侦察登舰。接回 H04–H06。 | 王国以撤离结果结算；永冬药车确实抵达；黑帆船只确实离港；两地的事实能够分别带回谷地。 |
| 3 | 京都完成现场核验，再接谷地 H07–H08。 | 玩家能亲手验证录播和实地通行冲突；旁路和断开执行器均能完成救援；记录继续可查。 |
| 4 | 埃及做可改变路线的水位与泄洪；奥尔良做分工与合击；秦帝陵做行、驻、转和工匠交接。接 H09–H12。 | 每域用自己的操作完成高潮；已交接的地方设施可回访；谷地具备登天所需的地面支援。 |
| 5 | 天穹观测冠、赫利昂三阶段战、机械隔离和回镇尾声 H13。 | 锁定后的攻击可被场地遮板反制；枪手和伙伴均参与；结局后玩家能走过居民修好的桥。 |

设计稿对黑帆与永冬的顺序，以及秦帝陵在后三域中的位置有不同安排。后续依赖暂用天空终章 V3 的结构：王国后开放黑帆与永冬，汇合到京都；京都后开放埃及与奥尔良，随后进入秦帝陵。地图继续沿用当前连续大陆，实装前用灰盒核对入口距离与谷镇回访节奏。

## 每轮交付

1. 先实现一条可走通的主路，再加能改变行动方式的替代解法和局部回访结果。
2. 验证新增任务正常输入、关键碰撞、存档恢复和相邻旧任务的交接。通常只跑直接相关的 World 用例，再做一次正式构建。
3. 更新本地启动构建，提交到 GitHub `main`，发布现有 Pages 网站，核对三个位置使用的 World 版本。World 开发提交集中在 `world/`。
