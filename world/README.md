# world/ — 幻日谷 (World 首区) 白盒

Parhelion Alpha 的大世界首区：程序生成的白盒地图（GLB）+ 浏览器第一人称查看器。

## World 00 · 幻日谷（World Architecture v1.0）

幻日谷是 2026 年的现代总部，地图扩大到 720 × 720 m（原来 480 m），可玩区 ±334 m：

| 区域 | 位置 | 内容 |
|---|---|---|
| A. 初始营地 | 南侧高台 | 出生点 |
| B. 幻日观测所 | 西南园区 | 观测终端、世界地图全息台、圆顶望远镜 |
| C. 枪械工坊 | 园区东侧 | 武器架 + 三道靶场（练习靶） |
| D. 召唤大厅 | 园区西侧 | 圆柱回廊和召唤阵，任务完成后亮起光柱 |
| E. 幻日塔 | 北 | 重启后三处时层断面显现 |
| F. 湖区与山口 | 中部 / 边缘 | 西部时层（落日王国）、北方冰海断面（永冬之城，冰面可走）、东部山口（星落海岸，无缝相连） |

主线 9 步：观测终端 → 领取装备 → 靶场 → 森林机关靶 → 中继器 A → 前哨站中继器 B → 幻日塔 → 调查三处时层断面 → 稳定召唤阵。
原来的回声森林、镜湖、雾瀑、废弃前哨站（原“旧观测站”）都保留在原位置。
设计说明见 [DESIGN.md](DESIGN.md)。这个目录是独立的，不依赖也不改动仓库里的其它部分（例如 Arena）。

## World 01 · 落日王国（白盒 v1）

约 537 年的不列颠，720 × 720 m，位于幻日谷正西（世界偏移 -720, 0）。从幻日谷西部时层断面沿峡谷无缝走进去；
召唤阵稳定（`summon_circle`）之前，断面口有一道看不见的门（`Seam_west_Gate`，`opensWhen`）。
生成：`npm run build:britain`（`tools/build-britain.ts` + `tools/gen/britain/*`）。直接从这里开始：`?region=britain`。

| 区域 | 位置（区域内坐标） | 内容 |

| 迷雾森林 | 东 (230, -20) | 断面石环、发光蘑菇、隐士林中祠 |
| 圣剑湖 | 中 (40, 90) | 木栈桥通向湖心岛，湖中之剑 = 与 Saber 缔结契约 |
| 骑士营地 | 东北 (170, -200) | 木栅营地、帐篷；射倒 3 个试炼木人 → 碎片·誓约 |
| 卡美洛外围 | 西北高台 (-190, -190) | 城墙、城镇、集市；主塔外侧螺旋坡道 → 碎片·王座 |
| 圆桌大厅 | 城内 (-215, -165) | 圆桌 13 席；点燃 3 个火盆 → 碎片·圆桌 |
| 卡姆兰战场 | 西南 (-200, 200) | 焦土、断矛；集齐契约 + 三碎片后点亮落日之核（Boss 空位之王占位） |

远处西北山脊上是真正的卡美洛（远景，Alpha 不可进入）。黄昏天空、区域流式加载在后续步骤。
`validation/britain.test.ts` 走通：断面门、峡谷 → 湖、栈桥、营地、王城 → 圆桌、主塔螺旋、卡姆兰。

## 运行

```bash
cd world
npm install
npm run dev          # 打开 http://localhost:5173
```

地图文件已经提交在 `public/assets/`，直接运行即可。修改了 `tools/gen/*` 之后重新生成：

```bash
npm run build:world  # 重新生成 world_alpha.glb + world_alpha.layout.json（同种子结果一致）
npm run build:coast  # 重新生成区域 2「星落海岸」world_coast.glb + layout
npm run build        # 类型检查 + 打包到 dist/
```

## 区域 2：星落海岸（Starfall Coast）

![星落海岸](docs/coast_overview.png)

和幻日谷是**同一个无缝世界**：从回声森林往东走，穿过东侧山口，就能沿着山脊走到守望灯塔所在的海岬；`?region=coast` 可以直接从海岸码头出生。两个区域在同一场景里加载，碰撞、空气墙、小地图、水面和草地都统一处理（`src/regions.ts`、`src/grid.ts`）。

性能方面：生成器产出的整图合并网格在加载时会切成 64 m 的分块（`src/chunk.ts`），这样视锥剔除、阴影剔除和远距离隐藏都能生效。默认是中画质：不开 GTAO，分辨率上限 1.25 倍，并会动态降分辨率保住帧率，草量减半。`?q=high` 打开全部特效，`?q=low` 适合低配机器。

- **潮汐码头**（出生点）：高脚渔屋、栈桥、渔船、灯笼。
- **风铃草原**：花海与草海。
- **白沙湾**：海蚀拱，可以踩着石柱跳上拱顶。
- **守望灯塔**：在海岬上，沿外侧螺旋坡道登顶。
- **星陨坑**：陨石核心周围是发光晶簇，旁边有上升气流。
- **浮空群岛**：6 座浮岛，靠上升气流和滑翔翼逐岛前进，岛下有瀑布。
- **断崖神殿**：从折返石阶或山脚上升气流上到崖顶高台。

任务线：收集 3 枚星之碎片（陨坑、浮空岛、海蚀拱）→ 点亮断崖神殿的星辉祭坛（光柱冲天）→ 点亮灯塔（旋转光束）。另有 6 个隐藏发现。

新玩法与渲染：

- 滑翔翼（原神式）：空中按 Space 展开或收起；进入上升气流后自动展开。
- 水面会按深度变色（浅滩青绿、外海深蓝），岸边有浪花线和向岸推进的浪带，两张地图都生效。
- 环境里有飘落的花瓣和花粉。上升气流有螺旋风粒子和风壁。
- 后处理：MSAA、GTAO、Bloom 和体积光。草海用 GPU 实例渲染；树冠采用原神式球形法线。

`validation/coast-smoke.test.ts` 用真实碰撞体验证了以下路线：出生点和传送点能稳定落地；上升气流配合滑翔翼可以依次飞到 i1、i2、i3、i4；折返石阶能上到崖顶；灯塔螺旋坡道能走到顶。

## 查看器修复与验证（2026-10-26）

- 只有进入鼠标锁定且大地图关闭时，移动、互动、重置和射击才有效；ESC / 切出窗口会清除按键，大地图打开时清空并阻止操作。
- 飞行模式的 E 只负责上升，不会同时启动中继器；传送和切换飞行会清除旧的落地/游泳状态。
- 小地图的 X/Z 坐标分别使用正确的视口偏移。
- 地图布局先检查 HTTP 响应与数据结构；加载失败显示原因和“重新加载”按钮，鼠标锁定失败也可以再次点击。
- 保留地图生成器、美术资产、布局与总体风格，不涉及 Arena。
