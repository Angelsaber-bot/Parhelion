# world/ — 幻日谷 (World 首区) 白盒

Parhelion Alpha 的大世界首区：程序生成的白盒地图（GLB）+ 浏览器第三人称探索查看器。

## World 00 · 幻日谷（World Architecture v1.0）

幻日谷是 2026 年的现代总部，地图扩大到 720 × 720 m（原来 480 m），可玩区 ±334 m：

| 区域 | 位置 | 内容 |
|---|---|---|
| A. 初始营地 | 南侧高台 | 出生点 |
| B. 幻日观测所 | 西南园区 | 观测终端、世界地图全息台、圆顶望远镜 |
| C. 枪械工坊 | 园区东侧 | 武器架 + 三道靶场（练习靶） |
| D. 召唤大厅 | 园区西侧 | 圆柱回廊和召唤阵，任务完成后亮起光柱 |
| E. 幻日塔 | 北 | 重启后三处时层断面显现 |
| F. 湖区与山口 | 中部 / 边缘 | 西部时层（落日王国）、北方冰海断面（永冬之城，冰面可走）、东部山口（黑帆尽头，无缝相连）、南方鸟居断面（业火京都，千本鸟居） |

主线 9 步：观测终端 → 领取装备 → 靶场 → 森林机关靶 → 中继器 A → 前哨站中继器 B → 幻日塔 → 调查三处时层断面 → 稳定召唤阵。
原来的回声森林、镜湖、雾瀑、废弃前哨站（原“旧观测站”）都保留在原位置。
设计说明见 [DESIGN.md](DESIGN.md)。地图生成器独立维护；运行时共享仓库根部的 `assets/weapons` 美术与 `shared-client` 操作设置，不导入 Arena 战斗规则。

## World 01 · 落日王国（白盒 v1）

约 537 年的不列颠，720 × 720 m，位于幻日谷正西（世界偏移 -720, 0）。从幻日谷西部时层断面沿峡谷无缝走进去；
召唤阵稳定（`summon_circle`）之前，断面口有一道看不见的门（`Seam_west_Gate`，`opensWhen`）。

## 运行

```bash
cd world
npm install
npm run dev          # 打开 http://localhost:5173
```

地图文件已经提交在 `public/assets/`，直接运行即可。修改了 `tools/gen/*` 之后重新生成：

```bash
npm run build:world  # 重新生成 world_alpha.glb + world_alpha.layout.json（同种子结果一致）
npm run build:blacksail  # 重新生成 World 02「黑帆尽头」world_blacksail.glb + layout
npm run build:winter     # 重新生成 World 03「永冬之城」world_winter.glb + layout
npm run build:kyoto      # 重新生成 World 04「业火京都」world_kyoto.glb + layout
npm run build        # 类型检查 + 打包到 dist/
```

## 操作

| 键 | 作用 |
|---|---|
| 点击画面 | 锁定鼠标进入 |
| WASD / Shift / Space | 移动 / 奔跑 / 跳（空中再按 Space 展开滑翔翼） |
| E 或右键按住 | 第三人称肩射瞄准；视野缩放、双手持枪抬起 |
| O | 按键 / 普通与开镜灵敏度设置 |
| 左键 | 射击（可打机关靶） |
| F | 互动（中继器、控制台） |
| M | 大地图 |
| 1–7 | 传送到各区域（调试） |
| V | 三维自由飞行调试：W/S 跟随镜头俯仰升降，A/D 横移；不新增手动升降键 |
| T | 契约后召唤／收回 Saber，可在设置改键 |
| C | 显示碰撞体 |
| G | 任务指引开/关（屏幕路标 + 光柱 + 地图标记，跨区域会先指向东侧山口） |
| R | 重置进度 |

正常新开局／重置会空手回到初始营地，在枪械工坊的武器架领取曙光 AR 后才可射击与肩射。重置任务与装备但保留语言、按键、灵敏度和画质等个人设置；战败复活不清空进度。详见 [重置行为与验证](../docs/WORLD_PROGRESS_RESET.md)。

URL 参数（截图/调试）：`?region=blacksail`（黑帆尽头）、`?region=winter`（永冬之城）、`?region=kyoto`（业火京都）、`?region=britain`（落日王国）、`?q=low`（低画质）、`?spawn=station`、`?cam=x,y,z,yaw,pitch`、`?clean`（隐藏 HUD）、`?lit`（点亮光环）、`?nofog`。

## World 02：黑帆尽头（Black Sail's End，1718）

![黑帆尽头](docs/blacksail_overview.png)

1718 年的加勒比海，海盗黄金时代的最后一年。它取代了原来的星落海岸原型，放在幻日谷正东（区域偏移 x +720，720 m 见方）。召唤阵稳定后，东侧山口的门就会打开，沿山口栈道一路走下去就是拿骚港，中间没有传送门（`?region=blacksail` 可以直接从栈道出生）。

- **山口栈道**：从幻日谷的东侧山口下到海边，路边有绳栏和灯笼。
- **拿骚港**：三条栈桥，每条旁边停着一艘可以走上去的帆船（中间那艘挂黑旗）。另有酒馆（黑胡子在这里，契约标记也在这里）、绞刑架广场、集市和造船厂（藏宝图其一）。
- **走私者草原**：起伏的草地，有风车（藏宝图其二）、糖厂废墟和走私者洞口。
- **黑胡子要塞**：建在海崖上的星形要塞。炮台高出胸墙，先装填大炮，再站在炮位上击沉海上的 3 艘幽灵小艇，就能拿到碎片·火药。
- **浮空沉船群**：风暴漩涡上方悬着 5 艘沉船。踩上发光的上升气流，一艘接一艘滑翔上去，最高那艘上是碎片·罗盘。
- **骷髅礁**：沿沙洲走过去不用游泳。旁边沙嘴的尽头有一艘半沉的商船（藏宝图其三）。三片藏宝图拼齐后，X 标记亮起，在那里挖出碎片·藏宝。
- **亡航灯塔 + 幽灵舰队**：灯塔可以沿螺旋坡道登顶，顶上亮着冷灯。拿齐三枚碎片后，从灯塔石码头会出现一条幽灵栈桥（有碰撞），连过三艘幽灵船通到旗舰「安妮女王复仇号」。在旗舰上点亮海之核会触发 Boss 亡航提督，击败后冷灯熄灭、风暴散去，然后回酒馆和黑胡子签约。

天色：越往东走越接近暴风雨前的灰绿色天空，点亮海之核以后转晴（`src/twilight.ts`）。战斗系统现在支持每个年代各有一个 Boss（`BOSSES`，`src/combat.ts`），各自有独立的解锁条件和通关存档。

`validation/blacksail.test.ts` 用真实碰撞体验证了以下几点：山口门在召唤阵稳定前挡得住；从幻日谷能走到拿骚港；所有传送点都能稳定落地；酒馆、造船厂、风车、栈桥都能走到；要塞路线能上到炮位，炮位对三艘小艇的射界通畅；上升气流能把人依次送上 W1 到 W4；沙洲和半沉船都能走到；灯塔能登顶；幽灵栈桥出现前过不去，出现后能一路走到海之核。

## World 03：永冬之城（Everwinter City，1812）

![永冬之城](docs/winter_overview.png)

1812 年冬天的俄罗斯，拿破仑大军从莫斯科撤退的那一年。放在幻日谷正北（区域偏移 z −720，720 m 见方）。召唤阵稳定后，北方冰海断面的冰门打开，顺着结冰的海湾一路往北走，冰面就接上了别列津纳河，中间没有传送门（`?region=winter` 可以直接从渡口出生）。

- **寒冷机制**：在永冬之城里体温会慢慢下降（左上角有体温条）。靠近篝火、余烬、点燃的烽火或皇帝帐篷可以回暖；体温降到 0 会冻僵，移动变慢、不能冲刺。点亮冬之核以后寒冷解除。
- **别列津纳渡口**：冰河上两座浮桥（下游那座断在河中间），河上散落着丢下的马车和大炮。
- **大军营地**：一排排帐篷和营火。拿破仑在蓝白条纹的皇帝帐篷里，契约标记也在这里。
- **烽火雪原**：三座小山上各有一座烽火，点齐后，中间的鹰旗冢上出现碎片·鹰旗。路边有冻住的行军队列。
- **燃烧的莫斯科**：烧毁的木屋区，余烬还能取暖。
- **克里姆林宫**：红砖城墙和塔楼、教堂群、沙皇钟和沙皇炮。伊凡大帝钟楼南面搭着十段脚手架，爬到顶上的钟楼平台拿碎片·钟声。
- **冰封峡谷**：沿冰河往东走进峡谷，冰墙挡住了去路。击碎两侧崖壁和冰墙上的 3 枚冰封印，冰墙崩塌，后面的冰窟里有碎片·霜晶。
- **红场**：圣瓦西里大教堂前是冬之核。三枚碎片拿齐后点亮它，触发 Boss 执冬者，击败后雪停、太阳出来，然后回皇帝帐篷和拿破仑签约。

天色：越往北走越接近低沉苍白的冬日天空，点亮冬之核以后转晴（`src/twilight.ts`）。拿破仑和后面的宫本武藏一样只放了契约标记，从者模型不在这一章的范围里。

`validation/winter.test.ts` 用真实碰撞体验证了以下几点：冰门在召唤阵稳定前挡得住；从幻日谷沿冰面能走到渡口和大军营地；所有传送点都能稳定落地；上游浮桥能走过河；能走进皇帝帐篷；三座烽火和鹰旗冢都能走到；斯摩棱斯克大道能走上莫斯科、进克里姆林宫南门、到红场冬之核；钟楼脚手架能一路爬到碎片·钟声；冰封印从河面上看得见、打得到，冰墙没倒时过不去，倒了能走进冰窟。

## World 04：业火京都（Kyoto Ablaze，1582）

![业火京都](docs/kyoto_overview.png)

1582 年 6 月 21 日凌晨，本能寺之变的那一夜，以京都为舞台。放在幻日谷正南（区域偏移 z +720，720 m 见方）。幻日谷南边新开了第四处时层断面「南方鸟居断面」（召唤阵现在需要调查四处断面）。召唤阵稳定后，从断面穿过一条千本鸟居隧道翻过稻荷山，下山就是京都，中间没有传送门（`?region=kyoto` 可以直接从稻荷楼门出生）。

- **千本鸟居**：几十座朱红鸟居连成的隧道，出口是稻荷楼门和两尊石狐。
- **洛中**：棋盘式街道，两侧是町屋。离本能寺越近，房子烧得越厉害，屋顶上还有火。
- **鸭川三条大桥**：宫本武藏在桥上等你，契约标记也在这里（从者模型不在这一章的范围里）。河水很浅，可以蹚水，也可以踩下游的乌龟跳石过河。
- **东山**：八坂神社的朱红楼门和八坂塔。沿三年坂的石阶一路往上，穿过仁王门到清水寺，在悬空的清水舞台上拿碎片·舞台。舞台下面是音羽瀑布。
- **金阁寺**：金阁背后围着竹篱，只能踩着镜湖池里的石头和小岛走到金阁前的钓殿，碎片·金阁在那里。
- **明智军阵**：西山上的桔梗纹阵幕。射落山脊上的 3 面桔梗大旗，阵幕里会出现碎片·桔梗。
- **本能寺**：护城河、土墙和角楼围起来的寺院，本堂正在燃烧。东门有桥过河，院子中央是京之核。三枚碎片拿齐后点亮它，触发 Boss 业火之主，击败后全城的火熄灭、天亮，然后回三条大桥和武藏签约。
- **罗城门遗迹**：城南只剩基石的平安京正门。

天色：越往南走越接近被火光映红的夜空，点亮京之核以后转为黎明（`src/twilight.ts`）。

`validation/kyoto.test.ts` 用真实碰撞体验证了以下几点：鸟居断面的门在召唤阵稳定前挡得住；从幻日谷穿过千本鸟居能走到三条大桥；所有传送点和出生点都能稳定落地；三条大桥和乌龟跳石都能不湿脚过河；能走进本能寺东门到京之核；跳石能一路走到金阁的钓殿；三年坂能爬到清水舞台；从明智军阵入口看得见、打得到三面大旗，阵幕里的碎片能走到。

## 查看器修复与验证（2026-10-26）

- 只有进入鼠标锁定且大地图关闭时，移动、互动、重置和射击才有效；ESC / 切出窗口会清除按键，大地图打开时清空并阻止操作。
- E 和右键均为按住肩射，F 互动；按用户最新要求移除了手动飞行升降。V 仅切换水平飞行调试，不能用俯仰或旧升降输入改变高度；正常跳跃、出水、滑翔与上升气流保持原规则。传送和切换飞行会清除旧的落地/游泳状态。
- 小地图的 X/Z 坐标分别使用正确的视口偏移。
- 地图布局先检查 HTTP 响应与数据结构；加载失败显示原因和“重新加载”按钮，鼠标锁定失败也可以再次点击。
- 保留地图生成器、美术资产、布局与总体风格，不涉及 Arena。

- World 游戏视角固定第三人称，不再用 V 切成 FPS；固定相机 URL `?cam=` 仍仅用于调试截图。

- O 或进入页设置按钮打开主／副按键、普通/开镜灵敏度与反转Y设置，保存于当前浏览器；与Arena设置独立。两个按键是“或”关系，不是组合快捷键。旧 v1 保存自动迁移至 v2，保留自定义映射和灵敏度，只删除已移除的升降字段；冲突逐项修复并明确通知，不整套重置。可恢复默认，动态提示跟随改键。
- 松开瞄准、Esc、地图、设置、失焦、游泳/滑翔/飞行都会清除肩射状态。其他5类未有战斗规则的模型没有伪装成World可用武器。
