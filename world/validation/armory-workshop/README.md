# 幻日谷枪械工坊修补 · 2026-11-05

本次针对领取步枪与弹药、后接靶场的 **枪械工坊**，位于 `[-74, 10, 250]`，交互为 `armory_rack`。它与从者生活馆是两栋不同的建筑。

修补前：敞口仓库的门面和室内大片空白，武器陈列只有横条，工作台是发光长方体，入口铺装边缘穿草。

修补内容：

- 门面增加工坊铭牌、门框护脚、分缝、通风百叶、墙脚防护及分区标识。
- 旧武器架的横条用作承托导轨，增加九件有枪托、枪管、握把、弹匣、瞄具与扳机护圈的陈列，区分步枪、霰弹枪和冲锋枪轮廓。
- 中央维修柜增加抽屉、拉手、工具垫、夹具、纸张和检修零件；两侧墙面增加工具挂板、仪表、护板、顶棚工字梁、斜撑、线槽和悬挂照明构件。
- 清理工坊、原有西侧铺装及靶场的草遮罩，保留周围草地。

原 Alpha 地图文件、碰撞三角形顺序、装备架坐标、任务和装备解锁条件均保留。细节贴合已有墙体、台柜和武器架，不在原有两条过道添加家具障碍。新增 11,088 三角面，合并为三个静态绘制批次，沿用距离剔除，无新增图片下载或点光源。
