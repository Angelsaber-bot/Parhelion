# 大世界生活场景与交互验收 · 2026-11-05

本轮覆盖五个生活据点、全部 19 名居民、116 个真实宝箱、283 个交互标记，并补查旧地图中外观像宝箱但只有发现提示的物件。

## 已定位并修复

| 问题 | 原因与处理 |
| --- | --- |
| 王国城门居民过于简陋 | 城门事件仍单独创建球形头部和六边形外套的临时人物。改用正式居民脸部、发型、衣服、手指与配饰；各自独立的腿部关节支持护送，保留原事件路径和存档。补充眨眼、注视、呼吸和清理资源逻辑。 |
| 生活馆像空壳 | 重做有顶门廊、立柱、斜撑、真实窗洞及内窗帘、百叶窗、墙脚、角石、封闭阁楼、室内吊顶和地板接缝。床从 4 米长修正为 2.35 米，增加圆角床垫、缝线、衣柜、扶手椅、亚麻织物与餐具。 |
| 低矮铺装被草覆盖 | 旧遮罩只排除高于地面 0.6 米的物体。改查独立建筑碰撞，并一次性排除五个据点、坡道及连接路径；城门归人路线增加连续铺装。 |

| 幻日谷湖心石柱与瀑布洞穴金色方块不能打开 | 原来只有静态几何和自动发现标记。移除静态假箱，接入正式箱盖动画、奖励、弹药补给和防重复领取存档；旧发现记录保留。 |
| 黑帆藏宝完成后仍显示闭合宝箱 | 该箱原本只在剧情奖励已领取后出现。改为有内部空间的开盖空箱，领取状态与剧情条件保持一致。 |
| 共用箱盖开盖时内侧露空 | 半圆柱缺少切面，原箱体又是实心方块。为四档宝箱补齐箱盖木质底面、内侧撑条与铰链，箱体改为真实四壁、底板和四边框。新增逐角度正面材质射线验收，覆盖闭合、半开、全开。 |
| 湖中平台与踏石表面闪烁 | 支撑柱顶与盖板顶位于同一平面。让支撑柱止于盖板下方，并补足平台盖板对柱体的覆盖；可站立顶面高度保留。 |
| 材质呈单一色块 | 五个据点增加共享木纹、灰泥、石材、布料、纸与瓦面细节，使用带多级渐远过滤的程序纹理，无额外图片下载。居民增加贴体剪裁、翻领、口袋、围裙和鞋扣，减少微小眼球的过量细分来维持面数预算。 |

## 可复现检查

在 `world` 目录运行：

```sh
node --import tsx --test validation/lived-world-quality.test.ts
node --import tsx validation/lived-world-audit.ts validation/lived-world
```

`lived-world-quality.test.ts` 运行正式入口、真实地图和碰撞，逐个将角色落稳，再通过正式交互按键打开 116 个箱子；挖掘箱等待正式升起动画，封印箱显式设置前置完成条件。检查重复开启不重复发奖，以及湖心、断塔、洞穴和石柱的真实高度。它还验证草遮罩、真实窗洞、居民护送、面数与重复释放安全。

`audit.json` 是实际入口和实际资源的结构台账。所有箱子有对应动作，交互标记无重复，运行错误为空。洞穴上方的岩石顶盖是预期结构，不作为宝箱埋藏问题。台账是无 GPU 的结构检查；浏览器截图另用于画面检查，不把结构检查等同于实机帧率或逐帧动画审美。
