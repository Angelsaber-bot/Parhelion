# 三从者连续动作验收步骤

此分支以已上线的 `6be0f8e` 为基线，集中打磨武藏、黑胡子、拿破仑的连续动作。
模型资源保持原样，不修改招募、伤害、冷却、碰撞或存档规则。
本文件是测试步骤，不代表本分支已经发布或全量验收完成。

按键以默认绑定为例；改键后使用设置中的对应键：

1. **选择与普通动作**：按 Y 选择已招募从者，T 召唤。缓走、跑动、停下并改变朝向，
   接近普通敌人观察从者自动攻击。黑胡子仍使用火枪；拿破仑仍骑白马持长剑。
2. **武藏 Q**：先跑动，再停下施放 Q。观察出场步态向攻击姿态的衔接；
   刀光应较少遮挡身体，但不承诺所有地形完全无滑步或穿插。
3. **武藏 X**：通过正常战斗积蓄能量，满能量后按 X。
   检查起势镜头是否连续拉开、双脚支撑、第三式后的先后收刀和最终恢复；
   默认设置下白光更弱，“减少特效”仍是另外的可选设置。
4. **黑胡子与拿破仑**：观察黑胡子射击前后空闲手臂是否突然缩回；
   拿破仑站定转向时应有小幅换蹄，而非四蹄姿态固定地旋转。这个换蹄不是地形锁脚。
   分别测试 Q、X、收回/重召唤，并确认结束后可正常转镜头、行走和再次战斗。

不要用旧截图或旧演出视频判断新分支；请核对最终交付中的源码版本与验证说明。
如从旧网址切到新 localhost 地址/端口，存档是按地址隔离的：先在旧地址导出 JSON，
再到新地址导入。新地址显示新存档，不代表旧地址的数据被删除。
