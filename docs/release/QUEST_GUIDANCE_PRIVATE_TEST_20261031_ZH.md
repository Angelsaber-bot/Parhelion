## 任务怎么找

1. 在 World 按 **Esc** 释放鼠标，打开 **「任务指引 · 主线、支线与探索」**。默认显示当前地区；可以切换地区、主线／支线／探索，或显示已完成。
2. 看卡片上的**当前操作、目标名称、地区与直线距离**，再点 **「追踪下一步」**。仅打开菜单不会改变追踪，也不会完成任务。
3. 回到游戏跟随当前目标标记。默认 **G** 可显示／隐藏指引；默认 **P** 返回原主线。改过键位时使用自己的绑定。距离不是道路长度，光柱不是自动寻路。
4. 完成真实操作后，目标会推进到下一步。例如练习靶按未命中的顺序更新；藏宝图收齐后指向宝藏；幽灵艇任务先指向要塞大炮，上炮位后才指向未击破的艇，**不要跟着目标游下海**。
5. 跨年代尚未开放时，卡片会说明先稳定召唤阵；点 **「返回当前主线指引」**继续原任务。不会替你打开通路或补写旧任务。
6. **「五居民纪事与伪晓续篇」**按钮进入原来的故事进度面板。五位居民与续篇仍按既有现场步骤推进，不是新的远程完成按钮。

### 快速检查

- 打开菜单、筛选、切换语言：任务记录不应改变；Esc 应返回菜单。
- 追踪一个多步任务：完成一步后应换到下一项；已完成任务可查看，但不能重复领取完成。
- 去一个探索点：只有进入它原本的发现范围才记录，不是点“追踪”就发现。
- 接近未解锁的支线奖励：应先引导真实前置，而不是直接让你操作锁住的目标。
- 返回原主线或切换到居民纪事：只保留一个明确的当前追踪目标，不把所有新任务铺满小地图。
