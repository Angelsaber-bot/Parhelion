# 10 月 31 日更新：游玩与自查指南

这是仓库内的说明，**不代表已经发布到公网或更新了你电脑上的版本**。以下内容以已通过整体验证的源码检查点 `67f6a1a` 为准。新剧情是本同人游戏的原创续写，不是官方剧情。

## 一分钟入口

进入 **World → 暂停菜单 → 主线续篇与归路纪事 · 故事进度**。先追踪岚，修接收机并带上武器，再沿西岸渡口桥去调查「伪晓回声」。新内容包括可选海港／雪原路线、阵列战与保存结局，以及五位居民的现场纪事和五套可解锁武器外观；原主线与旧存档继续保留。Arena 则改进了规则提示、加载取消与重试，不要求换一套操作。

## 从哪里开始

打开 World 暂停菜单里的 **「主线续篇与归路纪事 · 故事进度」**，主动追踪想看的故事。它只指向下一处目标，不会远程完成任务；默认 **P** 可恢复原主线指引。跨时代仍需完成原主线的召唤阵条件，纪事不会替你打开封闭的通路。

### 主线续篇「伪晓回声」

1. 在幻日谷聚落找到 **守频员·岚**，交谈并完成接收机的两步检修；从原来的武器架取得装备。**不必先完成全部五篇居民纪事。**
2. 去谷地旧收讯阵的记录器调查。干路是：**过西岸渡口的桥，再沿西岸向北**。指引目标的直线不是步行道路，低洼捷径会经过水域。
3. 追踪信使后，自选 **黑帆港口截讯** 或 **永冬雪原守台**。只走一条即可继续；另一条不会自动通关。雪原第二波需要再次主动接通；附近火盆恢复体温，不是回血或回能装置。
4. 带回线索，返回谷地阵列。防守中按 **I 收讯 → II 转发 → III 播送** 操作发射器，再面对守门者。发射器反馈很短，不会弹长对话打断战斗。
5. 最后在阵列台选择保留求援频道，或封存复制回路。**选择会保存；重复交互不能切换另一个结局。**

旧通关存档可以接着玩，不需要重置。旧主线记录会被承认，但不会自动完成新对话、现场步骤或结局。

### 五位居民在哪里

各时代聚落的小型工作棚与值守台都有用途；找不到时，在纪事中追踪对应篇章。

| 地区与现场 | 居民 | 这篇在做什么 |
|---|---|---|
| 幻日谷·归航讯号亭 | 岚，守频员 | 修接收机，选择播报归路或守听来声 |
| 落日王国·誓言见证棚 | 艾妲，见誓人 | 辨认名册，为名字或归来的人安排位置 |
| 黑帆尽头·潮汐值守台 | 玛拉，潮汐守望员 | 核对归港讯息，安排旅客或补给优先 |
| 永冬之城·暖路担架棚 | 米哈伊，担架员 | 整备担架，安排庇护或护送路线 |
| 业火京都·纸灯避难廊 | 澄，抄录人 | 护住纸页，安排记录或休息空间 |

每篇都有交谈、两步操作、安排选择和回访；部分阶段需要原主线的实际进展。**做完现场工作不等于整篇完成，要回来听居民的结果。** 五篇完成后，还可回岚的发信板作最后的归路记录；它不是「伪晓回声」的必需条件。

## 新涂装怎么看

完成对应居民纪事后，打开设置（默认 **O**）的 **「旅途涂装」**，选择「枪械与近战外观」：

- 岚：**回声电台**；艾妲：**留名之誓**；玛拉：**归港潮汐**。
- 米哈伊：**雪线余温**；澄：**纸灯余烬**。

它们改变 World 步枪与近战武器配色，步枪另有克制的纹样；**不加伤害、不改变判定，也不是 Arena 装备解锁**。续篇结局本身不另送涂装。导入未解锁的存档或重置后，即使保留外观偏好，也只显示原版。

## 战斗与动作变化

- 敌人的挥击、枪口反馈更贴合实际攻击接触时刻；不同剑兵的蓄力与收势有所区别。普通近身敌人的同时预警更有节制，小障碍附近的移动尝试有上限，没有因此新增一群常驻敌人。
- 守门者用直刺、横扫和蓄势放射区分招式；盾牌姿势**不表示额外无敌**。看预警、利用收招空隙。实体掩体也会挡住你的射线，必要时横移，不要对着柱子持续开火。
- 主角起跳收腿、下落伸腿、落地承重与转身重心更明确，没有因此新增镜头震动。部分从者的演出与收势也有调整。
- 真实近地支撑更连续，减少坡面微小间隙让地面操作被错误拒绝或截断；这不是空中起闪、延长无敌或隔空站稳。Saber 的步幅与地形脚部支撑已调整，从者遇到局部障碍也会尝试有限绕行；并不保证任何复杂地形都能自动找到路。
- 玩家脚部会在支持的坡面作有限贴地调整，不改变角色位置、移动速度或命中判定；跳跃、滑翔和近战等动作仍保留原有控制。瞄准右臂也作了受手腕角度约束的调整，减轻部分枪托与衣袖交叠，但不是完全无穿插。
- 设置中的 **「降低技能闪光」** 和奥义演出选项可减少刺激；缩短或跳过演出不会返还已经消耗的能量。修改需要重载的画面项前，确认进度已保存，必要时导出备份。
- Arena 的赛前规则、加载取消/重试反馈更明确；**在线打开菜单不暂停比赛**，离线暂停行为不同。原有模式、离线/LAN 选项与对战规则保留。

## 操作没有换一套

以下是 World 默认键位；改键后以设置和现场提示为准。

| 操作 | 默认输入 |
|---|---|
| 交互、继续对话、确认已选答案 | F |
| 瞄准 | E 或鼠标右键 |
| 近战 / 闪避 / 技能 / 奥义 | B / Z / Q / X |
| 召唤或收回从者 / 切换从者 | T / Y |
| 快速旅行 / 恢复原主线指引 | N / P |
| 帮助 / 设置 | H / O |

对话先用方向键或数字选答案，再用自己的交互键确认；不会默认选第一项。某个数字或方向键被绑定为交互时，优先执行确认。绑定为交互的滚轮方向也可继续对话。

玩家与从者奥义不是同一种施放方式：召唤状态影响施放者；玩家定向奥义可能打空。查看展开的帮助说明，不要把能量消耗当成命中保证。

## 建议亲自检查的 8 件事

1. **旧存档入口：** 不重置，打开故事进度追踪岚；新篇章仍需实际交谈与操作。
2. **路线：** 沿西岸渡口桥的干路到旧收讯阵。原主线中继器 B 不要求清空敌人；幻日塔按西侧跑跳、空中再按自己的跳跃键展翼、外缘落稳后再跳的路线攀登。没有新增步行坡道，跨时代条件不变。
3. **选择：** 在发起遭遇的选项里直接按交互键，不应默认开战；主动选定后再确认。
4. **中断恢复：** 先备份，在未完成遭遇中离开，再回原控制台；应需重新接通，不能凭离开获得胜利。已保存的调查、完成波次和接受的发射器步骤应保留。
5. **阵列：** 先碰 II，再按 I→II→III；观察顺序提示与接受后的灯光变化，确认没有长对话暂停战斗。
6. **结局：** 完成后保存并重新进入，再看阵列台；应保留原选择，另一条未走路线不应显示通关。
7. **涂装：** 完成居民最终回访，在设置切换对应涂装与原版；看步枪和近战武器，未解锁项不能冒领。
8. **动作与操作：** 在平地和缓坡走动、瞄准、起跳与落地，看脚部和持枪变化；用自己的改键切换中英文、翻页和选择，试试降低闪光。Arena 取消加载后应能重试；在线菜单不暂停比赛。

保存失败或出现保护提示时，先按提示导出资料，不要急着重置。普通 JSON 备份用于恢复进度；**「无损原始记录」是修复资料，不是可直接导入的普通存档。** 若原记录根本无法读取，不会提供不存在的原始数据下载；先备份当前页面进度，再重新载入重试。取消替换不写入；另一页面在确认期间创建或改变存档时，也不会用旧页面的进度直接覆盖它。

## 当前边界

已进行自动状态检查、真实主程序输入路径检查和实际模型离线画面审查；这**不能代替你的设备上的人工游玩、GPU 画面或帧率验收**，也没有据此承诺通关时长。断点恢复保留已保存的任务步骤，不是每个敌人的即时血量与动作。

本检查点已包含真实近地支撑连续性、玩家有限地形脚部支撑、Saber 步幅／地形支撑、从者局部绕行、受手腕角度约束的瞄准手臂调整，以及酒馆屋顶内侧修补，且整体验证通过。Saber 原有的低垂持剑可能触地、个别枪托接触衣袖的问题并未因此宣称完全消除。

尝试过的幻日塔步行坡道已撤回，保留原地形与分段攀登路线；当前提示只是解释已有动作，不是新建通路。

Arena 获取鼠标控制失败时会保留继续／离开入口，可主动重试；在线菜单仍不暂停服务器。World 成功导入进度后若页面没有重新载入，旧场景不能继续游玩，请使用明确的重新载入按钮。部分旧存档读取失败时不会自动写入残缺的新存档；先备份当前页面进度，再按提示检查。
