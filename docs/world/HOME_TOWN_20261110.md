# 主角城镇 · 家、入住与完整镇务

主角城镇位于九宫格东南 (720, 0)，西侧归乡大道接幻日谷，北侧驿道朝黑帆尽头。地图不设内部区域墙；保留连续大陆与现有主线入口。当前版本完成城镇环境、主角家、公共住所、Saber 入住、居民活动及可追踪的镇务与日常设施。

## 建筑、道路与室内

20 栋独立建筑：两层主角家、归乡公馆、面包房、杂货铺、咖啡馆、裁缝铺、修理铺、诊所、港湾仓库、修船棚，以及十栋普通住宅。建筑有实体墙、门洞、地板与封闭屋顶；室内家具避开主要通道。外立面有窗框、百叶、雨水管、烟囱与店名牌；侧窗和后窗为真实墙体开口与透明玻璃，保留实体玻璃碰撞。沿街增加花箱、信箱、木箱和短篱，北街绕过诊所转角。

主角家含客厅、厨房、内侧楼梯、楼上卧室与书桌。楼板为楼梯留出实际开口，可从门口不跳跃登楼并返回。公馆前部是公共餐厅与厨房，后部中间走廊连接两翼八间客房，每间有床、书桌与书架。Saber 的房间在西翼靠南一间。

八条路线：下港主街、北门驿道、广场回家、公馆入口、庭院至北坡练习庭、花园生活环线、南岸散步道、北街。各建筑门廊通过独立缓坡接街面。广场、花园、庭院和练习庭设铺地；路灯、长凳、公告板、菜园及植树补充公共空间。港口有仓库、修船棚、小灯塔、石岸和伸入潮湾的木栈桥。建筑与公共铺地、道路排除地面草，外围草地保留。

## 如何开始

沿幻日谷东侧归乡大道进入归乡广场，或预览 `?region=home`。广场公告板可接受和回报镇务；八位居民可交谈问路，园丁与港口管理员沿真实地面巡行，玩家接近或交谈时停步。

亲自站上广场后登记「归乡广场 · 家」安全据点，可在据点旅行面板返回。它与幻日谷同属现代，不要求开启历史时层；仍需脱离战斗、安静五秒并落到安全地面，不恢复生命或改变主线进度。

已经在圣剑湖与 Saber 缔约的存档，在归乡公馆入口内侧的「入住簿」明确选择邀请。尚未缔约时只解释条件，不制造契约记录。登记以后行李与房间陈设出现，邀请不会自动修改同行偏好；再次使用入住簿可以让她留家休息或一起出发，原有召唤键仍可使用。

Saber 不在同行状态、玩家靠近公馆且地区资源就绪时，同一个现有角色会在客房、走廊、餐厅和庭院之间步行。日常路线沿真实房门与通路设置，使用原有碰撞导航。接近她或交谈会停步，暂停菜单停止行走。同行时沿用原来的同伴逻辑，不复制第二位 Saber，不更改玩家已选外观。

可以进行首次「欢迎回家」对话，在厨房准备一份热饭，或邀请一起出发。共同用餐目前表现为准备好的餐桌和短对话，未制作坐席、进食动作或多人聚餐演出。庭院有第二段可选交谈。

主角家客厅可休息，每次沿用既有安全恢复规则恢复最多 25 生命；需要脱离危险并安静五秒。楼上书桌显示实际完成的王国、黑帆出港、永冬运输与京都取证记录。家中内容不授予武器、章节、Boss 或其他契约进度。

## 镇务与设施

到广场公告栏明确接受「归乡镇 · 把日子接起来」，四件事可自由顺序完成，全部完成后回到公告栏亲自回报。任务日志支持中英搜索、地区筛选、追踪下一步与已完成显示。发现地点不代替操作，完成操作也不自动代替最终回报。

- **送面包**：在面包房柜台边拿篮子，亲手穿街走进公馆厨房收货台。篮子跟随手部，交付后保留在厨房台面。普通步行跨门槛的短暂离地不会丢失；菜单、攻击、受伤、游泳、飞行、滑翔会将未交付的篮子放回面包房。未完成搬运为瞬态，读档可重新领取。
- **起船绞盘**：石岸上选中绞盘，松开后持续按住交互五秒。小艇先吊离水面，再移到修船滑台，绞盘、缆索、船体及碰撞一起变化。未完成时移动、攻击、受伤、离开或菜单会中断并回到初始位置；完成位置保存。
- **校准灯塔**：塔脚西侧的手轮持续操作三秒，灯罩朝向外海航道，透镜与导光束出现；完成状态保存。
- **花园供水**：手压水泵持续操作三秒，手柄运动、水沟显水、花圃开花；完成状态保存。

另有两个可重复日常：

- **射击练习**：在北坡练习牌开始本轮，击中三面不同的蓝靶。需要已在原工坊领取装备；沿用真实瞄准、枪口遮挡、弹药与射击伤害流程，不生成战斗敌人或奖励章节。重复击中同一面不重复计数。离开、暂停或失去安全地面结束当前轮，完成记录保留，随时可以再练。
- **垂钓**：栈桥尽头抛竿，等待浮漂下沉，三秒窗口内按当前交互键提竿。过早按会提示等待，错过可直接重来，无饵料消耗。钓获银鳍鱼后记录速写并放生；纪念保存，等待、咬钩等瞬态不跨读档恢复。

## 店铺与家

- 面包房提供热面包休息；诊所提供治疗，沿用安全恢复规则，不改变最大生命。
- 修理铺为已经领取的装备补充最多六十发弹药；空手旧档不能借此获得武器。
- 杂货铺与裁缝铺提供海风蓝、晚霞玫瑰、花园苔绿三套家居布艺配色，修改家中地毯并保存，不影响武器和战斗数值。
- 咖啡馆报纸根据灯塔与花园的真实状态更新。园丁、港口管理员和照管人也会随供水、起船和送餐状态改变台词。
- 家中的纪念架记录镇务回报、三靶练习与银鳍鱼速写；未完成项保持空缺。

## 保存与后续范围

入住、欢迎、共餐、庭院对话、镇务设施、最终回报、练习、垂钓和家居配色使用各自 `home_*` 标志，沿用现有进度导出、恢复和完整重置。旧存档可直接继续。未完成的搬运、操作、垂钓和练习不会在读档或重置后偷偷恢复。它们不授予章节、Boss、契约或新武器事实。

其他从者先预留客房，随人物主线扩展；当前常驻和入住演出仅 Saber。普通店铺有服务和实际居民，不新增交易货币或资源刷取。共餐目前仍为准备餐桌与短对话，尚无坐席和进食动画；复杂日夜日程、多人聚餐和终局共同归家仍属后续人物内容。
