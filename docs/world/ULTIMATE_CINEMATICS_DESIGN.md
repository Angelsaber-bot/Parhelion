# 全屏大招演出设计 / Ultimate Cinematics

2026-10-30 · Design specification, not implementation or visual-QA evidence.

## 目标与边界

四位从者优先：每人一段 **5.2 秒、覆盖整个游戏 viewport** 的独立专属舞台，包含角色特写、蓄势、释放、收尾。不能把现有标题横条加大后当作完成。采用二次元游戏式硬切、构图突变、轮廓光、干净色块和少量分层粒子；保留现有角色身份与技能名。拿破仑必须是**白马持剑**，不改为 FGO 炮兵。

只借鉴公开参考的演出结构，不下载或重用商业影片、音轨、配音、截图纹理。舞台、几何、动态线条和音效使用项目自产内容。标题只作为 0.6 秒的辅助信息，主体始终是角色和动作。浏览器 viewport 全覆盖，不调用操作系统全屏 API。

## 统一视觉规格

- 入口 0–0.25 秒：原世界画面以角色主题色擦除，HUD 隐去，仅保留右上跳过；不使用连续白闪。
- 角色特写占可用画面高度 65–85%，明确看见脸、持械手与武器的关系。超近镜只能短暂使用，不能全程裁掉武器。
- 舞台至少三层：远景身份地标/天幕，中景角色和主体动作，前景刀光/烟/雪；不是原地图贴色。
- 方向：默认主动作由左向右；武藏交叉穿越，Saber纵向聚能再横向释放；拿破仑有明显纵深位移；黑胡子横向揭示巨大炮列。
- 身份不用文字也能辨认：金色剑柱／黑帆炮列／白马骑兵／红蓝双刀。
- 收尾必须给出0.35秒以上的辨认时间再回到原世界，恢复原相机、HUD、输入、音量与暂停状态。

## 四位 5.2 秒分镜

以下秒数为**表现时间目标**，真实命中以动作接触事件为准，不得按表另写伤害定时器。release 窗口允许轻微重映射来吻合已有动作；额外火花、幻影、光线均不添加伤害。

### Saber — 誓约之光 / Oath of Light

配色：午夜蓝 `#101C49`，青白 `#CFF9FF`，剑金 `#FFD36A`。舞台为星海与镜面水地平线；不用海盗海浪或京都墨纹。

| 时间 | 构图 / 动作 / 镜头 | 反馈 |
|---|---|---|
| 0–0.55 | 蓝色风帘横扫，低机位全身拔出金剑；背景星点向剑收束 | 风声吸入，不闪白 |
| 0.55–1.35 | 三分之二侧脸特写，镜头缓推，前景持剑双手清楚；金色眼侧轮廓光 | 标题细字置下，不覆盖脸 |
| 1.35–2.55 | 切中远景，双手举剑，青色风环向上盘旋，剑尖形成窄金柱，衣摆后扬 | 升调并在释放前短暂静音 |
| 2.55–3.95 | 全身纵斩，镜头切至剑刃侧后方，金柱折为向远方贯穿的宽剑光；不是圆形爆炸 | **1次真实contact，138**；命中时局部金色冲击轮廓与短震动 |
| 3.95–5.2 | 金柱裂成细光羽，角色保持斩后低剑姿；星海恢复，金尘擦回原世界 | 尾音衰减，保留斩后姿态 |

### 黑胡子 — 黑帆炮列 / Black Sail Broadside

配色：深青 `#062D38`，海墨 `#070F1A`，火橙 `#FF9A42`。舞台为暴风海、侧舷黑帆剪影、木质甲板与三组炮口。不要改成剑光。

| 时间 | 构图 / 动作 / 镜头 | 反馈 |
|---|---|---|
| 0–0.55 | 海雾覆盖原世界，低机位出现甲板和靴子，黑帆横掠画面 | 海风/低频船体响 |
| 0.55–1.35 | 肩部以上近景，火枪抬起指向远方；另一手发令，帽檐轮廓鲜明 | 枪机咔哒；表情/头部姿态，不靠标题表现性格 |
| 1.35–2.55 | 镜头快速横移拉远，揭示三层/三组炮口，远方浪头分开；引火线橙光爬行 | 火枪作为指挥点火视觉，不额外结算伤害 |
| 2.55–4.15 | 三组炮口按原动画contact依次后坐，炮弹轨迹划向同一远端，橙火被灰烟包住 | **3次真实contact，各48**；每次对应一组炮火与局部冲击；不得多打一轮 |
| 4.15–5.2 | 烟幕后黑帆掠过，角色收枪，焦橙火星向下落入青海 | 最后一声炮尾渐隐，烟雾转场回世界 |

### 拿破仑 — 帝国铁骑 / Imperial Cavalry

配色：冰蓝 `#BDE8F6`，帝国红 `#A72A38`，军金 `#E9BD63`。舞台为雪原与远端鹰旗/城门剪影。白马、剑、披风是主体；禁止加入肩炮、持炮、彩虹炮击。

| 时间 | 构图 / 动作 / 镜头 | 反馈 |
|---|---|---|
| 0–0.55 | 冰雪横向擦除，马蹄近景踏出碎雪，镜头上仰 | 一次清楚的马蹄声 |
| 0.55–1.4 | 骑手半身与白马头并置，拔剑指向前方，披风和鹰旗向后 | 号角式自产合成音；金属拔剑声 |
| 1.4–2.55 | 拉为骑手与白马全身；白马短暂抬前蹄后落地起跑，远景骑兵幻影排开 | 蹄声渐密；幻影是背景不新增目标/碰撞 |
| 2.55–4.0 | 贴地侧向追拍→前侧三分之二角，白马冲向纵深，骑手横向挥剑；剑弧金色，马迹蓝白 | **1次真实contact，155**；只在真实安全冲锋成立后启动，视觉不能越过障碍制造伤害 |
| 4.0–5.2 | 白马穿过雪雾减速，骑手高举剑，红金鹰旗从前景擦过 | 蹄声和旗声收尾，恢复原位置/路线状态 |

### 武藏 — 无空连刃 / Void Blades

配色：纸白 `#E9E8DF`，墨黑 `#111522`，绯红 `#F05A71`，靛蓝 `#778BFF`。舞台为墨色水面、圆月/圆形墨相与少量枫叶。双刀一直分色可追踪。

| 时间 | 构图 / 动作 / 镜头 | 反馈 |
|---|---|---|
| 0–0.5 | 一笔墨线纵向撕开原世界，白纸空间显现，角色处于侧面低重心 | 短促出鞘音 |
| 0.5–1.3 | 眼神与双刀护手的中近景；两刀交错在脸下，不遮住眼睛 | 红蓝两侧轮廓光，标题短暂出现 |
| 1.3–2.45 | 拉远见双脚与两刀，红刃向右、蓝刃向左展开；背后墨环凝结 | 空气被压缩的静默蓄势 |
| 2.45–4.15 | 第一刀红弧由左下向右上；第二刀蓝弧反向；第三击双刀交叉切开墨环，画面只留角色和巨大X断面 | **3次真实contact：48/48/60**；左右动作必须不同；第三击后不得漏出第四击 |
| 4.15–5.2 | 枫叶沿裂缝缓落，角色背向三分之二收刀，墨环断裂后归一 | 无白屏爆炸；最后一声刀鸣与黑墨擦回世界 |

## 与真实战斗同步（不可妥协）

已核对当前 `world/src/contractSkills.ts` 和 `world/src/worldActions.ts`：从者通过 `startPose → onContact → skills.contact(token) → flush → strike` 结算，不按静态 `pulses.at` 直接命中。保留此唯一事实来源。

1. 成功校验能量、冷却、目标/路径且原cast接受后才开幕。失败不播放假成功，仍遵守现有不扣能量规则。
2. 表现层独立角色克隆/舞台，不改真实世界坐标、朝向、目标或碰撞；拿破仑仍走安全路线验证。
3. 全屏遮住游戏时不允许玩家被隐藏敌人无声击杀。建议保存统一world simulation暂停状态，intro/hold/recovery冻结所有战斗时钟；release窗口推进原cast动作与必要simulation。不得只禁输入而让敌人照常攻击，也不得由UI关闭标志触发现有 `!enabled → cancel()`。
4. 将每个既有contact和其pulse编号映射为舞台释放反馈；真实伤害数量依旧是1/3/1/3，数值138/144/155/156，范围与目标上限不变。演出时间不是combat authority。
5. 渲染慢帧跨过多个contact时必须逐项消费，使用cast token与pulse去重；不靠 `time === marker`。
6. 跳过、Short和Off继续同一个cast，不调用第二次activate，不直接补伤害。未到contact时可恢复原战斗表现；已发生contact不能回放结算。设置改变不取消已消费的脉冲，也不补发不存在的脉冲。
7. Esc优先跳过/退出演出并恢复控制，不同时触发世界菜单或留下锁鼠标；失焦、重开、传送、角色切换、dispose、失败退出统一清理。恢复的是之前的状态，不硬设为running。
8. 若实现暂不能安全做到5.2秒presentation/simulation分离，先明确该限制并保留正确战斗；不可拿延迟伤害或假的HP动画掩盖不同步。

## 模式 / 无障碍 / 性能

- **Full**：四位各5.2秒；默认完整专属舞台。**Short**：约1.4–1.8秒，保留0.25秒特写、身份舞台与实际释放；**Off**：原世界施放与命中反馈，没有全屏遮挡。三种模式逻辑结果相同。
- 右上可聚焦“跳过 / Skip”，Enter/Space可用；不要求全屏、不抢浏览器权限。点击跳过只消费该点击，不能顺带攻击。
- 减少闪光：禁白屏、禁频闪，降低局部glow与对比跃迁；减少动态：关闭镜头抖动、快速变焦、密集粒子，保留角色关键姿势。遵循现有reducedEffects设置并允许独立选项。
- 不复制整个大地图。舞台可复用一个renderer，四套参数化背景和少量实例化几何；角色克隆复用已载入资源，避免每次cast编译shader或拉网络资产。
- 合成音效沿用项目音频设施扩展，不下载FGO音乐/台词；失焦/跳过必须停止持续音。静音下也能通过姿势与冲击读懂。
- 16:9、4:3、21:9和窄屏均不得黑边露出原HUD；窄屏改镜头而不是裁掉白马/双刀。安全区域内显示跳过。

## 验收证据

每人录完整演出并留至少5张阶段图（入口/特写/蓄势/释放/收尾）；实际运行截图才可标记GPU/浏览器画面，设计图或CPU离线图要明确标注。

逻辑回归：每种模式均核对真实伤害、contact数量、能量/冷却一次扣除；在入口、首击前、两击之间、最后一击后跳过；重复X/重复Skip；切换从者；拿破仑路径失败；失焦与恢复；低帧率dt；dispose/restart；reducedEffects；窗口resize。四位截图并排不读标题仍能区分。

探索者可后续做2秒通用“曙光反击”：青金径向符文→人物短特写→脉冲→归场，仍是原1次90伤害，不挤占四从者优先级。

## 当前实现 / 交付限定（2026-10-30）

本节描述当前代码，不将前文目标分镜冒充全部完成。当前是一轮**程序化专属舞台与镜头表现**，清洁度较首版有实质改善，但不是商业FGO等价制作，也不是新手绘/重新逐帧制作的动画。人物使用已有 Idle / Attack 动作剪辑：intro独立idle，charge抽样已有Attack前30%，release/outro复制真实施法角色局部姿态；现有attack剪辑重定时仍是伤害接触依据。四套背景、RGBA羽化能量带、黑胡子精修舰船是新表现内容。

### 已接入代码的行为与验证边界

- `main.ts`成功cast后启动director；Full约5.2秒，Short压缩引入/蓄力，Off不遮挡；skip保留同一付费cast。所有模式均冻结其他世界时钟，在release只推进原actions/actor并flush原contact。HP来自现有strike，不来自时间轴假伤害。
- `ultimate-lifecycle-dom.test.ts`使用生产DOM与真实模型，但明确NON-GPU；覆盖Full/Short/Off、不同时间跳过、失焦/隐藏恢复、renderer失败、切换/旅行限制与pagehide清理。每位期望真实伤害仍为138/144/155/156，施法激活一次；测试覆盖范围不等同浏览器/GPU验收。
- 场景复用源角色几何、材质和纹理，使用私有克隆骨架；stage只dispose自有舞台geometry/material和私有骨架，不释放源角色资源。end同时清空scene、actor/effects children及配对引用；dispose清除WeakMap framing缓存。已有反复释放/资源计数与源资源保留测试。
- `setAspect`在9:16的charge/release拉远人物构图，16:9/4:3/21:9保持景别；intro保持脸部特写，肢体或剑尖出框可能是预期近景，不应要求全身始终在框。stage测试含保守包围体检查；真实顶点CPU投影审查与离线图见下方补充，不等同GPU画面验收。
- 无障碍限制可在cast中途锁定，不能同一cast再返亮；程序化透明平面`forceSinglePass`避免Three DoubleSide双pass；离线Cycles不能认证此WebGL混合行为。

### 视觉审查结果与剩余限制

1. 最新羽化能量带实际以vertex RGB×material color、vertex alpha×opacity渲染，已修复多stroke共面造成的黑三角；不得把先前忽略RGBA的硬边图当最终证据。
2. 黑胡子背景使用已有纯几何船生成器的精修船体、索具、弧帆；三分之二舷角使帆面可读。最高桅帆仍可在构图上缘局部出框，这是背景剪裁，不影响人物/主要船体辨认。
3. intro→charge是明显景别切换（近景FOV32到42、距离改变），不是连续dolly。审查曾发现charge末独立Attack约30%姿态直接切回实时source的回跳风险；当前已加入**0.14秒仅视觉克隆姿态插值**，不延迟/修改真实actor或伤害时钟，该已知直接回跳问题已修复。release→outro仍有目标点/机位切换。静态投影或8张still不能证明这些过渡自然；必须用真实运行整段录像继续验收。
4. 已有镜头切换不自动意味着功能错误，但不能描述为“全套全新精细人物表演”。人物动作与释放高潮是否协调、实际屏幕混合、流畅度/帧率、音画同步仍需浏览器/GPU完整演出检查。
5. 当前离线证据保留真实stage相机、CPU蒙皮几何和GLB材质；Cycles方向灯/透明近似且未复现Three fog，不能冒称游戏GPU截图。

### 响应式证据与目标差距台账

- `world/validation/benchmarks/ultimate-stage-aspects.ts` 的最新诊断共 **432/432** 组实际CPU蒙皮顶点包围投影位于画框内，包含头发和武器：
  - 336组：4从者×21个原始Attack进度点（0–100%，每5%）×4种比例（16:9、4:3、21:9、9:16）。
  - 96组：4从者×6个charge→release早期插值时点（0、.035、.07、.105、.14、.175秒）×相同4种比例。
  - 此诊断仅覆盖指定原始剪辑及早期视觉插值抽样，不覆盖每个gameplay blend/contact，不判断遮挡、透明、完整运动或像素质量，**不是432张GPU截图**。
