# 前沿联络 · 突破演练：测试路线

本轮云端开发测试说明；不是已发布版本公告。原主线、旧存档和自由探索继续保留。

## 尽快看到新玩法

1. 打开暂停菜单的「任务指引」，在主线中追踪「前沿联络 · 突破演练」。未领装备时，目标先指向工坊武器架；只需要领取装备，不要求通关伪晓回声或旧主线。
2. 到停机坪旁服务庭院入口，主动确认开始演练。比较两种走法：正面借低掩体逼近，或走北侧维修路线绕侧面；不是必须清光敌人的关卡。
3. 到控制柜旁站稳，按住你当前绑定的「交互」键 **3 秒**。移动、受伤、攻击、松键或失焦会清空进度；中断后先松开，再重新按住。普通滚轮单次输入不能替代持续按住，测试时使用可持续按住的交互绑定。
4. 接通后，本场训练巡卫接令撤回。这不算击杀；即使先击败全部巡卫，也仍需完成接通。
5. 首次完成后，追踪菜单中的「前往部署板」。部署板就在庭院旁，选择后可安全前往旧前哨站南门外；不会替你启动中继器 B、授予契约或完成其他旧目标。也可以不部署，继续步行探索。

## 建议检查

- **新存档前置：** 未领取装备时，任务菜单引导武器架，而不是要求先打完旧章节。
- **路线选择：** 分别尝试正面掩体和北侧绕行，观察受到压制时能否改变接近方式。
- **中断反馈：** 接通过程中松键或移动，再停稳重按；进度应重新开始，不应偷偷累计。
- **停止/重试：** 离开、死亡或重新载入后，尚未完成的演练不能自动成功；回入口主动重开。
- **奖励保存：** 完成并正常保存后重载，部署权限应保留。再次训练不会重复授奖；训练进行中不能利用已解锁权限直接部署。
- **原任务不变：** 已完成中继器 B 不代表新演练完成；新演练完成也不代表中继器 B 完成。
- **菜单与改键：** 切换中英文、改用可按住的交互键，确认任务目标与接通提示仍清楚。打开菜单本身不应自动追踪或修改存档。

## 验证边界

纯状态、任务菜单和真实主程序的非 GPU DOM 测试用于检查前置、追踪、语言切换及幂等奖励；它们不能代替真实画面观感或完整战斗体验。场地通行、普通输入战斗和整体集成验收分别记录，不把测试用存档状态注入称作自然通关。
