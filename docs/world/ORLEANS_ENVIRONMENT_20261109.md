# 奥尔良 · 环境与探索细化

奥尔良已由地图框架推进为可连续游逛的沿河城镇。本次按旧区的建筑、室内、立体通行、居民互动和探索记录逐项检查；没有以建筑数量或面数代替美术质量判断。它仍在同一片大陆上，区域之间保留宽阔的陆地衔接，制作区块不会成为方形城界或空气墙。

## 已完成的地域特色

| 地带 | 实际内容与通路 |
| --- | --- |
| 河港与河门 | 下切的真实河床、连续石岸、四孔石桥、低位木桥与石制转接平台；踏轮吊机、晒网、系船绳、运粮货堆和带船舷、船桨、货物的小舟。河岸步道可接回街巷与河门。 |
| 商街与集市 | 五条街巷顺地形和道路形成街区，共 45 栋可进出的房屋。六种建筑分别采用挑楼、石拱商铺、装卸仓库、三层窄街屋、不对称作坊和凸窗转角屋，使用奥尔良独立构件组合。井、布棚、吊牌、厨房菜畦、晾衣架与梨树补充日常生活。 |
| 城墙与钟楼 | 城墙顺坡转折，实际道路穿墙处留开口；墙顶路线接修缮场木构坡道，钟楼外梯通过平缓转角平台登上三面眺廊，能俯瞰河港与城镇。 |
| 教堂与侧院 | 双塔、玫瑰花窗、尖拱门、扶壁与完整屋盖；开放中殿有实体石地、柱列和祭坛。外侧增加顺山坡的磨损石铺前庭、纪念园，以及带遮雨回廊、药草畦、长凳和水盆的开放庭院。 |
| 东墙修缮场 | 石块堆、工匠工作台、木料、施工布棚、破损运货车及真正可行走的上墙坡道，与普通营地形成不同轮廓。 |

民居内按用途设置货架、粮袋、箍桶、工作台、工具、床铺或书桌，中央保留通道。前、侧、后立面补齐窗框与构件；灰泥、石材、木构、蓝灰板岩使用独立表面细节。八处路灯有实际灯具及对应暖光，沿用共享灯光预算。

住宅朝向最近的地面街道。房屋地面依据旋转后整个占地范围确定，入口坡道连接真实街面与平门廊；不满足净空和坡度的陡坡地块不放置房屋。桥头道路增加落地缓坡肩，避免公共街巷斜穿道路边缘时卡脚。

## 活动与探索

八位当地居民已接入原有 F 交谈流程：港务书记奥黛特、布商露西、药草师艾莉丝、石匠马塞尔、守钟人雷米、渔人阿兰、西墙巡守和河港搬运工。各自有独立中英对话和用途明确的问路信息；搬运工持粮袋，渔人持网具，守钟人持绳圈。巡守沿城墙往返，搬运工沿码头往返；交谈或玩家靠近时停步。居民在实际碰撞表面落地，不改变旧区居民数据或章节事实。

九处实体地标已接入探索列表、主动追踪、到达记录和存档恢复：集市、城墙钟楼、教堂、河门、演武营地、河港、药草回廊、东墙修缮场及钟楼眺廊。当地目标面板显示发现数。跨区前往奥尔良探索点使用连续大陆上的实际位置，不生成虚构传送门或章节。

十条主／侧／高／地下路线为：正面城门、沿河侧路、城墙高路、木桥环线、码头巡行、码头进城坡道、教堂侧院、修缮场上墙坡道、钟楼外梯与三面眺廊，以及城墙下的旧引水道。另有五条普通街巷及所有住宅的街面—室内出入通路。

## 河港设施与地下通路

三处设施已接入实际站立交互、任务追踪及原有存档：

- **踏轮吊机**：石堤上的把手驱动双踏轮与吊索，五秒把运粮驳船上的粮袋抬起、横移，再落到真实石堤表面。完成后货物保留在堤面。
- **检修绞盘**：转动三秒，升起城墙下的九栅铁门。关闭时有实际碰撞；只有完成操作并记录后才允许通过。引水道有两端下坡入口、干燥石铺检修道、桶拱顶、石肋、侧沟与避让座台，连接河门与城内，中央仍保留头顶城镇地形。
- **钟楼报时绳**：在三面眺廊站稳，拉绳一点五秒，铜钟摆动并发出遵循游戏音量设置的钟声。完成后仍可间隔敲钟；重新载入存档不会自动响铃。

先按交互选中设施，松开再按住；进度提示会说明当前步骤。移动、跳跃、攻击、受伤、离开操作范围或打开菜单均会取消未完成操作。只有完整操作才写入各自的设施记录；到达地标不能替代。三个项目与九处发现分别显示，主线、契约与其他地区的进度不受影响。

## 验收与范围

- 正式资源上的十条路线与五条街巷均双向步行检查，不使用跳跃或飞行绕过障碍。
- 45 栋房屋逐户从街面进入、经过室内前后，再返回街面；检查门前坡道和室内地面。
- 验证实体河床、干燥河岸、教堂地面和屋盖、回廊遮雨与净空、屋顶封口及面朝向；居民检查落地、身体净空、巡逻、交谈停步及数据隔离。
- 116 项相关检查通过，含大陆十二处邻接面、旧区资源修复、居民系统、任务列表、主线导航、地区与材质隔离。其中包含实际主程序的奥尔良探索追踪与旧宝箱站立交互检查。正式构建通过；未运行或宣称全仓所有测试。
- 实际浏览器复验默认中画质的多处场景，无页面或着色器错误；另通过真正的 F 交谈及九处发现—重新加载存档流程，主线完成集合保持不变。该存档检查使用定位进入地标；物理步行由上述正式碰撞测试覆盖，不把它称为完整实机徒步通关。

本次完成地图环境、通行、普通居民与探索体验。贞德／黑贞从者模型和契约、围城主线、巨龙战及演武营地 Arena 入口尚未实现；地图中不以接近地标冒充这些内容完成。奥尔良巨龙仍是区域 Boss 的规划，独立终极 Boss 地图仍未开放。
