# 打开归路 · M1 首轮原型

> 本文保留早期原型阶段的记录。现行五区版本已补齐修院通路、居民行走、场景设施与后续主线；当前交付和最终验证以 [五区冒险更新说明](OPEN_WORLD_ALPHA_20261101.md) 为准。


这是首轮历史记录。后续新增可走维修架、居民肢体动作与五区主线整合，见 [五区冒险与平衡更新](OPEN_WORLD_ALPHA_20261101.md)。

本轮开始执行开放世界 V2 的王城优先建议。交付范围是现有王城东南门的一段可操作事件，尚不代表 12–15 分钟正式关卡或首小时重编完成。

## 进入与操作

新档完成圣剑湖契约后，王国当前目标指向城门告示。到现场交互启动两名普通敌人：射手与重击卫士。主街较暴露，左右低墙提供掩体；可以利用当前同行从者原有技能。

金色锁扣可直接射断，也可从左侧接近后交互拆闩。提前解除锁扣会被承认。随后到右侧绞盘，松开交互键再按住三秒；移动、攻击、受伤、菜单和离开范围会中断。界面显示操作进度。仅将交互绑定滚轮时，会提示改用可持续按住的按键。

城门打开后，画面与动态碰撞同步更新。两名原型居民沿现有城门中央路线行进，玩家需要留在附近；十米内的敌人使队伍等待。前进前检查地面高度与两条身体通行射线。抵达城内灯下后才记录救援完成，开放可交互补给点，并把主线指向圆桌第一盏誓火。补给复用现有脱战恢复规则。

## 进度与兼容

复用 `WorldProgress.done`，没有第二份任务存档。告示、锁扣解锁、开门、救援抵达分别提交。没有经验、货币或重复首通奖励。

开门事实永久保留；战败、离开游戏及重载不清除已提交事实。未抵达居民的临时移动从门外安全点重新开始。读档不会自动重建守卫遭遇，需要在告示主动开始。护送不以全歼为唯一条件，敌人远离队伍同样可以通过。

已有第一盏誓火、落日之核，或已满足旧版四项王国条件的存档，不被新门碰撞阻挡，也不失去旧 Boss 资格。尚未做过新事件的旧存档可以从任务日志「王城 · 打开归路」定位，补玩新动作。

## 验证范围

- 类型检查及生产构建。
- 状态测试：提前解锁、持续操作、受伤中断、按住不自动恢复、暂停、阻挡、战败重置、保存恢复、重复奖励去重。
- 原始王城 GLB 碰撞：整个居民路径的地面和身体通行、关闭门的阻挡。
- 实际入口与按键流程的非 GPU 测试：启动守卫、清除测试敌人、拆闩、绞盘、穿门抵达、章节目标及旧存档兼容。

非 GPU 测试使用替代渲染器，并通过直接施加伤害缩短战斗；不能作为画面、射击手感、难度、帧率或关卡时长的实机结论。

## 后续制作边界

本轮居民是简易头部与衣身模型，城门立即切换开放状态。侧向接近使用现有门外空间，尚未制作穿越修院的独立侧路、吊货遮线、完整居民动画、Saber 新短迎击，以及 12–15 分钟正式战斗节奏。新档谷地序章也保持当前流程。这些应在实机走查本段后继续完成，不能计入本轮已交付内容。
