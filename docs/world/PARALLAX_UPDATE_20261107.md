# 视差庭院与体验精修（开发中批次）

## 已接入正式游戏

在幻日观测所南侧新增「两步之间 · 视差庭院」。任务日志中可搜索“视差”或“Parallax”并追踪。到记录板接受观察，分别站到圆形／菱形脚印内，转动视角让双环处于画面中央，再按当前交互键记录。无需领取武器、瞄准或射击，没有计时。两个视角可以任意顺序完成。

回到记录板明确选择解释后完成。错误判断保留观察结果，可以重试；走远、飞行或在不符合现场条件时不能确认。进度沿用现有存档，已完成时可重读记录，不解锁旧主线或发放战斗数值。

完成后在设置的「旅途涂装」选择原创「折光测绘」。瓷白／深蓝分区上的观测环、黄铜标尺和青色基线应用于现有武器材质。未完成的旧档可补玩；恢复旧档或重置时沿用现有外观解锁规则。

庭院包含真实双环、叉形支架、转轴与螺栓、角度刻线、观察基线、01／02铭牌、双视角示意板和随地形铺设的地面。已清理设施、观察位与步道的草地遮挡。新艺术不移动原主线建筑或改变现有道路。
