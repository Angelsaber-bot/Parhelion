# Parhelion 连续大世界框架 · 2026-11-09

世界采用约 2160×2160 米、约 3×3 的整体尺度，全部区域位于同一片连续地形上。3×3 只用于安排制作尺度；地图内部没有空海面隔离带、按地图块封闭的山圈或区域空气墙。区域间既能沿路前进，也能离开道路从相邻陆地穿行。

旧五区的外围地形已经共同调整，原有地标、建筑、NPC 锚点和章节进度继续使用。后续可以继续改变区域形状与道路，不把旧框架当成固定限制。区域归属采用弯曲的地理过渡，地表颜色按世界坐标混合；归属切换只影响地区提示、天气及美术加载，不阻挡移动。

## 重建与预览

运行 `npm run build:continent --prefix world` 重建整片大陆：更新旧五区的地形，保留已精修的建筑及物件碰撞；把接缝带里的树木、灌木和石头落到新地面上；生成新三区，然后重建全部正式运行资源。只修改新区内部内容时，可用 `npm run build:expansions --prefix world`。

### 接缝规则（2026-11-10 起）

- **接缝高度取两侧实际地面。** 以前所有接缝都被拉到同一个大陆基准高度（约 16 m），而旧区两侧地面多在 3–9 m，于是接缝处出现一道笔直的土埂，内侧看起来像一道浅槽。现在每条接缝都有一条高度剖面，取两侧离接缝 50–120 m 处原始地面的平均高度，并沿接缝方向平滑；如果一侧是海，接缝高度不低于陆地一侧减 8 m。剖面存放在 `world/tools/gen/continent-seams.json`，由 `npm run build:seams --prefix world` 生成。
- **过渡带宽度不固定。** 过渡带宽约 55–125 m，沿接缝起伏变化，接缝两侧都不会出现平行于接缝的直线。四区交会点和四处剧情通道仍使用原来的高度。
- **已审定内容下的地面不变。** 旧五区里建筑、碰撞体、标记点和路线周围 10 m 以内保持原有地形，10–40 m 之间平滑过渡。保护遮罩在 `world/tools/gen/continent-protect.json`，用 `npm run build:seams --prefix world -- --protect` 从正式资源重新生成；只在代码里定义位置的内容，写入 `continent-protect-extra.ts`。
- **黑帆南侧海峡。** 原来这条海峡贯穿整块地图、紧贴古埃及接缝。现在西段改为低沙丘湿地，海面成为黑帆东侧海湾向西南伸出的一支；幽灵码头四周仍保留一片潟湖。
- **树石落地。** 旧区接缝带里的树木、树冠、灌木和石头，以及它们的碰撞体，按整件垂直移动到新地面上。落到海面以下的，以及会挡在接缝 45 m 以内开阔地上的大石，整件沉到地面以下。只改动坐标的 Y 分量，每处改动都记录在 `world/validation/join-band-seating.edits.json`。原有的逐字节保护测试先按记录还原，再与历史基准比对。
- **奥尔良—不列颠古道。** 卢瓦尔河桥头的路基高度只在奥尔良境内生效，古道进入不列颠后贴地而行，不再在接缝处悬空。

旧区使用地形替换流程，避免完整重排旧建筑与植被改变现有路线。底层单区生成器也使用共同地形规则；需要完整重做某旧区时，可单独运行对应生成器，再更新流式资源并检查原有任务路线。

## 验证

`continental-seams.test.ts` 检查十二处接缝都没有高出两侧地面的土埂，并逐件核对接缝带里落地的树石：每件都是整体垂直移动、位于接缝带内，并且贴在地面上或完全沉到地面以下。`continent-continuity.test.ts` 从正式资源读取地形，检查十二处邻接面的高度、原地图间的海面隔离带是否消失，以及离开道路后玩家能否双向步行穿越；同时检查西南地形和四区交会点。区域内部路线由 `expansion-framework.test.ts` 检查，旧主线通行、船队、城门、滑翔、运药车、战斗覆盖、地图展示与资源加载使用原有检查复验。
