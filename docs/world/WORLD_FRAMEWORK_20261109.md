世界采用约 2160×2160 米、3×3 的整体尺度，全部区域位于同一片连续地形上。3×3 只用于安排制作尺度；地图内部没有空海面隔离带、按地图块封闭的山圈或区域空气墙。区域间既能沿路前进，也能离开道路从相邻陆地穿行。

## 九宫格布局（2026-11-10 重排）

旅程从幻日谷出发，一排一排向北展开；每一站都挨着已经走过的地方。

```
 ⑦奥尔良    | ⑥古埃及 | ④业火京都
 ⑤秦帝国    | ③永冬之城 | ②黑帆尽头
 ①落日王国  |  幻日谷  |  主角城镇
```

故事顺序：幻日谷 → 落日王国 → 黑帆尽头 → 永冬之城 → 业火京都 → 秦帝国 → 古埃及 → 奥尔良。主角城镇挨着幻日谷，从一开始就可以前往。最终 Boss 地图仍独立加载，入口待定（中心上空或终点奥尔良地下）。

- **坐标原点不变**：幻日谷仍在 (0,0)，落日王国、永冬与幻日谷的相对位置不变，三者的世界坐标、接缝与剧情通道完全保留。世界范围为 x −1080…1080、z −1800…360。
- **平移**：黑帆尽头 (720,−720)，海湾仍朝东；奥尔良 (−720,−1440)。
- **转 180° 再放置**：业火京都 (720,−1440)、秦帝国 (−720,−720)、古埃及 (0,−1440)。三块地图的 GLB 和布局数据仍用原来的坐标，加载时整体转半圈（`REGIONS[].rotated`、`regionToWorld`、`placeRegion`）。转向后：京都的千本鸟居入口朝南对着黑帆，原来通往埃及的商队古道朝西接埃及；秦的驿道入口朝东对着永冬；埃及的日河仍流向外海，商队入口朝东对着京都。
- **新入口**：黑帆的西侧山口通永冬东侧山肩（剧情通道高度 16 m），京都的鸟居入口在黑帆北岸（10 m）；幻日谷的东山口通主角城镇（16 m），南侧封印门外是海岸。
- **跨区古道**：沙海商队古道（京都→埃及）、西境山河驿道（永冬→秦）、沙海西境古道（埃及→奥尔良）、归乡大道（幻日谷→主角城镇）。古道起点贴地，路面两侧的树石会沉到地下保持通畅。
- **主角城镇**（720,0）：已完成 20 栋可进入建筑、两层主角家、八间客房公馆、八条生活路线和港湾；Saber 可在契约后受邀入住，进行交谈、共餐与住所活动。其他从者随主线扩展，见 [主角城镇](HOME_TOWN_20261110.md)。

旧区代码里以世界坐标写死的内容已统一换算：黑帆 z−720；京都 (x,z)→(720−x, −720−z)。按旧坐标搭建的京都、黑帆附属场景（町家通道、冒险设施、本能寺桥头、旗舰货舱）整体移动或转向（`legacyFrameMatrix`）。京都的居民点也随地区转向。秦、埃及的台词与说明中的方位词已对调；京都的方位多为地名（东山、东岸关所等），没有改动。

## 重建与预览

运行 `npm run build:continent --prefix world` 重建整片大陆：更新旧五区的地形，保留已精修的建筑及物件碰撞；把接缝带里的树木、灌木和石头落到新地面上；生成新三区，然后重建全部正式运行资源。只修改新区内部内容时，可用 `npm run build:expansions --prefix world`。

### 接缝规则（2026-11-10 起）

- **接缝高度取两侧实际地面。** 以前所有接缝都被拉到同一个大陆基准高度（约 16 m），而旧区两侧地面多在 3–9 m，于是接缝处出现一道笔直的土埂，内侧看起来像一道浅槽。现在每条接缝都有一条高度剖面，取两侧离接缝 50–120 m 处原始地面的平均高度，并沿接缝方向平滑；如果一侧是海，接缝高度不低于陆地一侧减 8 m。剖面存放在 `world/tools/gen/continent-seams.json`，由 `npm run build:seams --prefix world` 生成。
- **过渡带宽度不固定。** 过渡带宽约 55–125 m，沿接缝起伏变化，接缝两侧都不会出现平行于接缝的直线。四区交会点和四处剧情通道仍使用原来的高度。
- **已审定内容下的地面不变。** 旧五区里建筑、碰撞体、标记点和路线周围 10 m 以内保持原有地形，10–40 m 之间平滑过渡。保护遮罩在 `world/tools/gen/continent-protect.json`，用 `npm run build:seams --prefix world -- --protect` 从正式资源重新生成；只在代码里定义位置的内容，写入 `continent-protect-extra.ts`。
- **黑帆南侧海峡。** 原来这条海峡贯穿整块地图、紧贴古埃及接缝。现在西段改为低沙丘湿地，海面成为黑帆东侧海湾向西南伸出的一支；幽灵码头四周仍保留一片潟湖。
- **树石落地。** 旧区接缝带里的树木、树冠、灌木和石头，以及它们的碰撞体，按整件垂直移动到新地面上。落到海面以下的，以及会挡在接缝 45 m 以内开阔地上的大石，整件沉到地面以下。只改动坐标的 Y 分量，每处改动都记录在 `world/validation/join-band-seating.edits.json`。原有的逐字节保护测试先按记录还原，再与历史基准比对。
- **奥尔良—不列颠古道。** 卢瓦尔河桥头的路基高度只在奥尔良境内生效，古道进入不列颠后贴地而行，不再在接缝处悬空。

旧区使用地形替换流程，避免完整重排旧建筑与植被改变现有路线。底层单区生成器也使用共同地形规则；需要完整重做某旧区时，可单独运行对应生成器，再更新流式资源并检查原有任务路线。
