# Parhelion 连续大世界框架 · 2026-11-09

世界采用约 2160×2160 米、约 3×3 的整体尺度，全部区域位于同一片连续地形上。3×3 只用于安排制作尺度；地图内部没有空海面隔离带、按地图块封闭的山圈或区域空气墙。区域间既能沿路前进，也能离开道路从相邻陆地穿行。

旧五区的外围地形已经共同调整，原有地标、建筑、NPC 锚点和章节进度继续使用。后续可以继续改变区域形状与道路，不把旧框架当成固定限制。区域归属采用弯曲的地理过渡，地表颜色按世界坐标混合；归属切换只影响地区提示、天气及美术加载，不阻挡移动。

西南已补齐连续的丘陵地形，作为王国与京都之间的林地延伸；树木、遗迹与当地活动仍待布置。海岸位于大陆外围，黑帆尽头保留其原有海湾及船队水域；卡姆兰西侧和京都南侧神社保留自然伸出的干燥岸地，避免海岸调整淹没旧探索内容。局部湖泊、河道、护城河和实际建筑属于各地内容。

十二处相邻地带都提供宽阔陆地连接，包括新区之间的奥尔良—永冬、永冬—秦地，以及秦地—黑帆、黑帆—埃及等方向。原有三条新区连接道路继续作为导航道路，周围地形同样可通行。

## 奥尔良环境细化

秦帝国已完成环境第一轮：骊山、三条地上路线、三层错开的地宫和可转动兵俑阵列的军令机关，见 [秦帝国 · 骊山上下](QIN_ENVIRONMENT_20261110.md)。

奥尔良已细化为可游逛的沿河城镇，包含 45 栋六类独立建筑、实体室内、石桥与木桥、踏轮河港、顺坡城墙、钟楼外梯、双塔教堂、药草回廊与修缮场。八位居民可交谈，两位沿城墙和码头巡逻；九处地标可记录、追踪并保存；踏轮吊机可运粮，绞盘能升起检修栅、接通旧引水道，钟楼可拉绳报时，三项设施独立保存。范围、制作入口与实景记录见 [奥尔良环境细化](ORLEANS_ENVIRONMENT_20261109.md)。古埃及仍为原框架。

## 新区制作范围

古埃及目前完成地形、占位建筑、地标体量与路线框架；奥尔良已完成当前环境、普通居民及探索细化；秦帝国已完成地上地下环境与第一处可操作机关（军令台转动兵俑阵列）。奥尔良后续安排先战黑贞，再与贞德、黑贞共同对抗巨龙；古埃及后续制作光影机关与神殿探索；秦帝国后续制作敌人与机关联动、升降机关和居民。从者模型、主线、完整战斗机关、特色战斗和 Arena 入口仍在制作范围内，其他两区普通 NPC 也待制作。到达探索地标只保存发现记录，不授予虚构的章节或 Boss 完成记录。

秦帝国主峰约 150 米，宫城台基约 70 米；地宫三层约 46、28、10 米，位于山体内部，只有宫后斜道和石料场检修道两处洞口。最低层仍高于全局海平面，避免被当前游泳规则误判为水下。

七个幻史域完成后进入独立终极 Boss 地图。它目前只记录规划，尚未开放；奥尔良巨龙属于奥尔良区域 Boss。

## 重建与预览

运行 `npm run build:continent --prefix world` 重建整片大陆：更新旧五区的地形，保留已精修的建筑及物件碰撞；生成新三区，然后重建全部正式运行资源。只修改新区内部内容时，可用 `npm run build:expansions --prefix world`。

旧区使用地形替换流程，避免完整重排旧建筑与植被改变现有路线。底层单区生成器也使用共同地形规则；需要完整重做某旧区时，可单独运行对应生成器，再更新流式资源并检查原有任务路线。

运行 `npm run dev --prefix world -- --host 127.0.0.1 --port 4177` 后预览：

- [幻日谷](http://127.0.0.1:4177/)
- [奥尔良](http://127.0.0.1:4177/?region=orleans)
- [古埃及](http://127.0.0.1:4177/?region=egypt)
- [秦帝国](http://127.0.0.1:4177/?region=qin)

地形规则在 `world/tools/gen/continent.ts`，整体布局在 `world/src/map/worldPlan.ts`，区域识别与外边界在 `world/src/map/regions.ts`。

## 验证

`continent-continuity.test.ts` 从正式资源读取地形，检查十二处邻接面的高度、原地图间的海面隔离带是否消失，以及离开道路后玩家能否双向步行穿越；同时检查西南地形和四区交会点。区域内部路线由 `expansion-framework.test.ts` 检查，旧主线通行、船队、城门、滑翔、运药车、战斗覆盖、地图展示与资源加载使用原有检查复验。

连续地形阶段的浏览器截图和记录位于 `world/validation/expansion/`，该阶段 166 项检查通过。奥尔良后续细化的当前结果以 `world/validation/orleans/validation-summary.json` 为准，包含 116 项相关检查与实际交谈、探索存档复验。不同阶段的检查数不混合为一次全仓验收。

正式构建通过；三个新区的框架曾分别完成浏览器加载检查，奥尔良细化后另行完成多视角实景复验。未宣称全仓测试通过。
