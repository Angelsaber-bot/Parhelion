# Parhelion 大世界框架 · 2026-11-09

本轮交付是接入现有 World 的三个可探索地图框架。城市、地标和多层路线使用占位建筑表达体量；NPC、角色模型、区域机关、任务、战斗和 Arena 入口仍需后续制作。

## 总体布局

世界以约 3×3 的整体尺度规划，当前覆盖约 2160×2160 米。720 米是制作定位的参考间距，不是区域形状，也不要求一张地图只占一个区块。地理轮廓、连接道路、区域归属和美术加载范围分别处理。

下表仅表示方位，不代表九张方形地图：

| 西侧 | 中央 | 东侧 |
| --- | --- | --- |
| 奥尔良：围城、河门、钟楼、教堂 | 永冬之城：保留现有内容 | 秦帝国：骊山、行宫、三层地下王城 |
| 落日王国：保留现有内容 | 幻日谷：初始区与现代总部 | 黑帆尽头：保留现有内容 |
| 西南地理留白，后续供山脉、海岸及旧区延伸使用 | 业火京都：保留现有内容 | 古埃及：绿洲、峡谷、巨像、太阳神殿 |

世界结构是一处初始区域、七个幻史域，以及七域完成后开放的独立终极 Boss 地图。终极地图不占据西南空格；目前只记录规划，没有可进入的最终战。奥尔良巨龙始终属于奥尔良区域 Boss。

本轮保持原五区位置、生成资源与存档规则，新增三个不规则轮廓。边界与区域识别已支持多边形，后续旧区可以逐段增加自然边缘与跨区扩展，不需要整体搬迁或重做。

## 已接入的三个区域

| 区域 | 本轮空间骨架 | 特色内容的后续方向 |
| --- | --- | --- |
| 奥尔良 | 守城集市、低位河门、城墙平台、钟楼、教堂高地、骑士演武营地；正面、沿河、城墙高路 | 围城救援与城市恢复；先对抗黑贞，再由贞德、黑贞和玩家共同屠龙 |
| 古埃及 | 商队绿洲、砂岩峡谷、双巨像庭院、太阳神殿、引光试炼台；峡谷侧路与神殿上层绕行 | 光影改变道路与敌人；可操作镜面、太阳巨像 Boss 与商队生活 |
| 秦帝国 | 骊山工匠集镇、行宫、铸造层、俑阵层、地下王城；地表高度约 64 米，地下楼层约 46、28、10 米 | 地上地下机关联动、调兵与破阵、地下守御中枢 Boss |

秦帝国的“地下”相对于山体表面计算，最低层仍高于全世界海平面，避免被当前全局游泳规则误当作水下空间。现阶段以敞开的剖面展示地下结构，便于检查坡道、净空和层间关系；封闭通道与最终建筑外壳后续补齐。

三处 Arena 场地目前仅预留空间。贞德／黑贞、奥兹曼迪亚斯、秦始皇没有被替换成其他从者模型；到达地标不会授予契约、章节通关或解锁终极地图。

## 与旧世界连接

- 落日王国北行，经北境围城古道抵达奥尔良守城集市。
- 永冬之城向东，经东境山河栈道抵达秦帝国工匠集镇。
- 业火京都向东，经沙海商队古道抵达古埃及绿洲。

连接道路有实际碰撞；坡度按旧地形采样，并向两端平缓过渡。旧地图的山体不被重新生成。当前道路属于空间验证用的栈道，后续会替换为符合当地主题的山口、河桥、驿道与峡谷构件。

## 制作与预览

运行 `npm run build:expansions --prefix world` 可同时重建三个新区的布局、原始 GLB、运行时核心与流式美术，并更新资源清单；只处理新区，不重新生成原五区资源。

本地运行 `npm run dev --prefix world -- --host 127.0.0.1 --port 4177`，然后访问：

- [奥尔良](http://127.0.0.1:4177/?region=orleans)
- [古埃及](http://127.0.0.1:4177/?region=egypt)
- [秦帝国](http://127.0.0.1:4177/?region=qin)

这些 URL 是制作预览入口；正常游戏仍从幻日谷开始。框架有独立的制作中说明，不向玩家显示虚构的可完成任务。

数据入口：`world/src/map/worldPlan.ts`。地图生成：`world/tools/gen/expansion/build.ts`。正式运行时从 `world/public/assets/world_{orleans,egypt,qin}.*` 读取，与旧世界使用同一加载、碰撞、大地图和渲染流程。

## 验证范围

`world/validation/expansion-framework.test.ts` 读取正式运行时核心资源，用真实 Player 胶囊碰撞检查三个区域的主路、侧路、高处路线与秦帝国下行坡道，并检查与旧区连接、地标落脚点和不规则地形范围。

`world/validation/expansion/browser.mjs` 用真实浏览器启动三个区域并保存画面及加载结果。自动路线通过不代表最终美术、Boss、剧情或机关已经完成。

本轮最终相关检查 114 项全部通过，包含往返通行、原五区战斗覆盖、55 种滑翔赛道／升级组合、运药车、存档路径、大地图及运行时资源；World 正式构建通过。开发过程中的全套首轮为 2053 项，出现的 16 项失败已修正并纳入上述复验，最终版本未再次运行整套 2053 项。记录见 `world/validation/expansion/validation-summary.json`。

秦帝国连接路从永冬之城南部雪原绕出，避开原有冰封峡谷滑翔赛道。新区域的预留地理方向没有被当成已经建成的跨区道路开放。

后续优先把每域的一段核心体验做完整：奥尔良夺回城门、古埃及打通引光神殿、秦帝国贯通工匠集镇与地下铸造层，再沿现有框架扩展。
