# 秦帝国 · 骊山上下（环境第一轮）

主题：骊山之上的帝国，骊山之下的不死王城。地上先给出驿道、集镇、关隘和宫城的秩序感，进入山体后再逐层露出仍在运转的铸造层、成片兵俑和星图王城。整片区域围绕一座完整的骊山展开，仍在连续大陆上：西接永冬（东境山河驿道），南接黑帆尽头，北、东两侧是外海岸。

## 地形骨架

| 骨架 | 内容 |
| --- | --- |
| 骊山主脊 | 西北支脊 → 宫后山口 → 主峰（约 150 m）→ 东脊，尖脊、凹坡，冲沟只切山腰。 |
| 宫城支脊与宫后山屏 | 从山口向西南经观阙、宫城一直伸到骊水关；宫后山屏把前殿台基包在山怀里。 |
| 宫前台地、南岭 | 托住外朝广场的宽缓山肩；南岭在驿道南侧收拢河谷，北坡做成梯田。 |
| 骊水 | 从关前流下，穿关墙涵洞、绕集镇北缘，沿驿道向西南流去；有真实下切河床，道路以桥面跨过。 |

地宫上方保证山体覆盖；只有两处洞口见天：宫后斜道（约 70 m）和北坡石料场检修道（约 28 m）。

## 地上

- 工匠集镇：铺石广场与水井、两条小巷、12 栋可进出的民居（夯土墙裙、白灰墙、黑瓦长檐四坡顶；陶铺、铜匠、粮囷、布铺四种门面，室内有土炕与箱柜）。窑场有两条龙窑（窑口火光）、晾瓦架和陶瓮；铸造棚有熔炉、风箱、铜锭和淬火槽；简牍库是带门的夯土库房，书架上成捆简牍；北坡石料场有阶梯式采面、待凿石块和木吊杆。
- 骊水关：峡谷中的双阙关门，关墙顺两侧山坡上行，溪水从涵洞铜栅下穿过。
- 骊山宫城：外朝广场（夯土台基、石铺中轴、两侧围墙）→ 门阙 → 龙尾道 → 前殿台基；前殿为朱柱、铜构、黑瓦大屋顶，殿前十二铜人，东西配殿。东北高台上是两层观阙，有坡道下到殿后院。
- 三条地上路线：
  1. 正门穿关：驿道 → 集镇 → 骊水关 → 山肩盘道 → 宫门 → 龙尾道 → 前殿。
  2. 沿水渠潜入：集镇 → 输水渠（低处走渡槽，石墩承托，渠水顺坡跌落）→ 宫城西侧水门与蓄水池 → 殿后院。另有岔道通石料场。
  3. 山脊绕行：集镇 → 窑场 → 西北支脊 → 主脊（四座烽燧）→ 宫后山口 → 宫城支脊 → 观阙 → 坡道下到殿后院。

## 地下

| 层 | 高度 | 内容 |
| --- | --- | --- |
| 上层 · 铸造与运输 | 46 m | 三座熔炉（炉口铜汁发光）、铜汁流槽与模具、陶俑部件工作台、纵向轨道与运俑车；马拉齿轮在顶上持续转动。 |
| 中层 · 兵马俑军阵 | 28 m | 90×60 m 大厅：东区静态俑坑、南墙俑列、中轴战车；两排共 8 组转台兵俑；天井光；三座军令台。 |
| 最深处 · 地下王城 | 10 m | 星图穹顶（约 220 颗星）、八条水银江河汇入环海、三级封土与铜椁、玉灯环、沿墙微缩宫阙。 |

三层水平错开，不整齐叠放；入口与出口分布在不同高度：

- 宫后斜道（70 m 入口）→ 转折平台 → 下行廊道 → 铸造层 → 运俑轨道斜坡 → 军阵东区。
- 石料场检修道（28 m 入口）→ 转折平台 → 军阵西区。
- 军阵中轴 → 斜井（铜闸）→ 平台 → 王城廊道 → 地下王城。

## 军令机关（调动兵俑、改变通路）

军阵大厅里有两排转台兵俑（东列 x=0、西列 x=-35，每排 4 组，每组 15.6×5 m、14 尊俑与掌旗俑）。兵俑顺着大厅纵深排列时，这一排连成整列、封住通路；横转过来时，组与组之间留出 10 m 通道。

- 守陵阵（默认）：东列封闭、西列让道、斜井铜闸落下。
- 让道阵：东列让道、斜井铜闸升起，西列合拢、封住身后的退路。

东、中、西三区各有一座军令台，按交互键切换两种阵式；两种阵式下每一座军令台都能走到，因此不会把玩家困住。兵俑用约 1.3 秒转过去，不是瞬间切换；有人站在转台扫掠范围内或铜闸下方时拒绝下令。阵式写入存档。

潜入路线：石料场检修道 → 军阵西区（守陵阵下西列已让道）→ 中区军令台改为让道阵 → 东列让开 → 运俑轨道 → 铸造层 → 宫后斜道 → 殿后院。同一个让道阵也开放斜井，通往地下王城。

## 验证

- `validation/qin-region.test.ts`（正式资源 + 运行时机关）：地宫各厅室和廊道都被山体覆盖且自带顶棚；两个洞口高差大于 30 m；三层中心水平间距大于 60 m。河床下切但不积水，梯田成阶，关隘位于峡谷，宫城台基和前殿屋顶为实体。12 栋民居逐户从门外进入、走到中心再出来；窑场、简牍库（经大门）、石料场可从集镇走到。两种阵式下的通行开闭、三座军令台在两种阵式下都可到达、转动过程、扫掠保护，以及“检修道 → 军阵 → 铸造层 → 宫城”潜入路线，只有转动军令后才能走通。
- `validation/expansion-framework.test.ts`：秦地 7 条路线（主路、水渠、石料场岔道、山脊、三条地下线）在正式碰撞上正反双向步行，不跳跃；每个地点都有实体地面；从永冬沿驿道步行进入。
- `validation/continent-continuity.test.ts`：永冬—秦地、秦地—黑帆两条接缝高度一致，离开道路也能双向穿越。
- 静音截图：`validation/qin/browser.mjs`（无头 Chromium、`--mute-audio`），输出在 `validation/qin/artifacts/`。

## 制作入口

- 单独重建：`npm run build:qin --prefix world`；预览：`?region=qin`。
- 布局数据（山脊、溪流、台基、地宫厅室与廊道、军令机关）：`world/src/map/qinPlan.ts`；地点与路线：`world/src/map/worldPlan.ts`。
- 地形：`world/tools/gen/qin/landscape.ts`；建筑与地宫：`build.ts`；秦式构件：`craft.ts`。
- 运行时机关：`world/src/environment/qinArmyOrder.ts`（主程序接入在 `world/src/main.ts`）。
