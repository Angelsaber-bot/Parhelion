# 主线人物篇与 Arena 皮肤 · 2026-11-02

## 游玩入口

World：暂停菜单 → 更多 → **主线 · 人物篇**。旧任务、契约与设置保留；首次领取装备的玩家会启用人物篇。跟随指引到生活馆旁的归航讯号亭，与岚交谈。五区的城门、船腹记录室、药车、京都与登塔流程继续使用。

Arena：大厅 → **皮肤工坊** → 选择武器和主题 → **装备皮肤**。支持拖动旋转、滚轮缩放；选择主题仅预览，点击装备后才应用并保存。八件武器都可以选皮肤，配装仍为两把不同枪械与一件近战。

## 剧情处理

保留“让明天继续”的主线骨架，补足人物的具体愿望与责任。岚的撤离回执成为贯穿四区的证据，而非新建另一套互相竞争的主线。

| 人物 | 新增主线场景 | 必须真实发生的交接 |
|---|---|---|
| 岚 | 求救坐标的开场、两地回执后的坦白、频道结尾选择 | 把原始记录留在现场；终局仍须停机、登塔、亲自撤离与记录 |
| 艾妲 | 征召册与家人的冲突、归人到达后的名字 | 居民实际穿门抵达，且王国核心解除 |
| 玛拉 | 等待女儿的港灯、“最后一班归航”及空泊位 | 商船实际完成离港，不能用击败提督代替 |
| 米哈伊 | 第十三分钟的同伴、药箱与人的不同交接 | 同一辆药车抵达并验收 |
| 澄 | 错地址与半个手印、原始命令和个人记录并存 | 京都异常解除，现场证据取回 |

人物场景只写入其本身的见面、回报、坦白和明确选择。打开对白、取消、离开、切换语言、重置后的旧按钮都不能完成救援或重复确认。原居民纪事从个人话题继续进入。HUD、任务册和路标会指向实际 NPC，而非已完成的核心。

两种结尾分别选择各地开放频道或五地轮班值守；结尾正文、回访对白和收讯台五路指示灯保存该选择。它们不授予伤害奖励。主线交谈有带地形遮挡检查的近景镜头，结束后立即恢复瞄准视角；口型和注视复用人物原有关节节点。

## 人物与皮肤美术

五位主线人物使用不同的脸部轮廓、眼睛、发型、服装与工作配饰；建模源码、GLB、Blender 编辑集合和离线近景见 `assets/characters/residents_v2/`。实机对话截图见 `world/validation/journey-drama-20261102/lan-dialogue.png`。

Arena 三套原创主题共 **24 款新增皮肤**：

- 星穹棱镜：深空烤漆、虹彩镀膜、星点与轨道纹样。
- 赤金日冕：暖白陶瓷、鎏金日轮、细刻纹和暖色光芯。
- 樱华琉璃：珠光釉面、玫瑰金刻花、花瓣与细流纹。

材质与纹饰作用于正式作战模型，支持第一人称、第三人称与近战武器；不改变枪口、握持点、弹匣关节、瞄具、伤害、攻速、射程和判定。目录采用追加方式，旧皮肤序号继续有效。独立实例拥有自己的材质和装饰，切换或关闭会释放；预览的迟到下载不能替换新的选择。

参考了 [Riot 的 Elderflame 制作说明](https://playvalorant.com/en-gb/news/dev/breathing-life-into-elderflame/) 的主题完整性与 [Valve 的武器涂装指南](https://www.counter-strike.net/workshop/workshopfinishes/) 的材质分区和表面处理。未使用其模型、纹样、贴图或音效。实际预览截图见 `arena-game/test/skin-showcase-20261102/`。

## 验证

新增人物篇验证覆盖开场确认、实体归路的四类证据、结尾选择与旧对白回退；角色验证覆盖六批次预算、面部变形、关节稳定性与释放。皮肤验证实际加载全部八件 GLB，核对三套材质实例隔离、装饰边界、锚点保持和作战状态一致性。浏览器逐一检查 24 款主题的加载与着色器，并验证装备保存、重载及三维显示。

正式发布仍须通过仓库的完整 Arena / World 测试、网站构建及公网联机检查；以对应发布工作流结果为准。原有生产包体积告警继续保留，不视为帧率或竞技平衡结论。
