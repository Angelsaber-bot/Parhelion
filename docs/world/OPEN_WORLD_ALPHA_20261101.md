# 五区冒险与 World 平衡更新

本轮目标：把原本并列的地区任务组织成能持续推进、能保存行动后果的五区冒险。所有新进度继续使用 `WorldProgress`，Arena 的数值与规则没有修改。

## 如何开始

运行 `world` 的本地预览后进入游戏。新玩家在领取装备后进入新冒险指引；也可以在开始菜单点击 **继续五区新冒险 · 保留已有存档**，从当前进度补做新行动。

已有契约、首通、发现和个人设置保留。原版章节已经通关时，新指引会利用这些成果，不要求重复击败 Boss。旧档可以继续原路线；主动选择新冒险后才切换新的章节编排。更多入口（据点旅行、旧纪事、独立突破演练和 Arena 对照）放在“更多旅途选项”。

推荐路线是谷地外联 → 圣剑湖契约 → 王国 → 黑帆与永冬 → 京都 → 回谷地终局。解锁后的四区仍可自由选择；先去京都不要求拥有从者。

## 实现的连续行动

| 地区 | 现在实际执行的行动 | 持续结果 |
|---|---|---|
| 幻日谷开场 | 领枪后选择服务庭院正面或维修侧路，持续接通控制柜 | 最低外联开放四条出谷道路，原中继器与登塔仍可探索，不伪造它们的完成记录 |
| 落日王国 | 在湖畔契约；选择正街或修院外墙维修架接近，射断或拆开锁扣，操作绞盘，护送居民穿门抵达，再点誓火与挑战空位之王 | 城门碰撞与画面开放，居民抵达独立结算，恢复补给点；旧档已打开的通路继续成立 |
| 黑帆尽头 | 要塞炮击三艇或在灯塔码头操作侧舷索具；从双侧舱口下到有碰撞的船腹记录室，取证后关闭断路器或击败舱口追兵，解除提督命令，亲自离舰，再到港口放行 | 商船实际驶离港口后才结算出港，行程检查点保存；回酒馆契约，基地出现港口服务 |
| 永冬之城 | 三座烽火或钟楼观察记录任选准备；射断两处支架或侧面拆闩，清开拒马；可用当地信号呼叫白马骑兵，在真实命中时提供一次突破；解除红场命令，放行药车并到渡口验收 | 宽街碰撞更新；同一辆药车沿经过审计的路线实际移动，途中存检查点，抵达与验收分开，基地恢复药箱服务 |
| 业火京都 | 三条桥会面；提前射倒的旗持续有效；正门、经过两间町屋的检修内巷或新增屋顶连接进入本能寺，解除异常后取得未覆盖的命令记录，再回桥契约 | 检修栈道的画面与碰撞一起开放；已有火势变化继续使用；记录进入回谷地终局条件 |
| 谷地终局 | 四区收束后关闭三处复制发射器；每处可在守卫仍存活时创造窗口完成，停机终止本处增援；击败讯号守门者，登塔手动接管，返回南侧集合点，再回观测所记录 | 停机、接管、撤离和结尾分别保存；原通路和居民后果保留；结尾允许继续探索与回访 |

默认目标、屏幕说明与路标读取同一组新冒险阶段。完成当地章节后会推荐下一段旅程，不会重新要求已绕过的旧谷地九步任务。玩家主动追踪纪事、日志任务或探索线索时，保留其选择。

## 平衡方向

| World 步枪项目 | 更新前 | 更新后 |
|---|---:|---:|
| 近距离基础伤害 | 16 | 12 |
| 射击间隔 | 0.14 秒 | 0.18 秒 |
| 连射后散热 | 8 发 / 1.1 秒 | 6 发 / 1.35 秒 |
| 满伤害范围 | 18 米 | 12 米 |
| 最低伤害倍率 | 45% | 20%，48 米起 |
| 敌人射击判定范围 | 150 米 | 70 米 |
| 场景机关射线 | 150 米 | 仍为 150 米 |

普通敌人与四区 Boss 血量保持原值。重击卫士在非破绽状态承受 70% 步枪伤害；敌人收势时步枪获得 1.3 倍反击收益。远射仍能提前处理威胁，但不能替代所有近战窗口与伙伴协作。

Saber 现有战技命中后可以打断正在蓄力的敌人，普通敌人的打断冷却为 5 秒，Boss 为 10 秒，硬直不超过 1 秒。技能仍经过原有目标、路径、距离、命中与资源校验；本轮没有宣称另做了一套新迎击动画。

地区的归路行动完成后，该区普通野外敌人进入和平状态；主动 Boss 重演与独立试炼保留。恢复过的旧中继与骑士试炼和平状态不会被其他地区的结算覆盖。

新冒险中的寒冷保留体温和风雪提示，但不会剥夺行走或冲刺，冰霜遮罩上限降低至 25%。未切换新冒险的旧路线维持原规则。

## 回访与可选内容

四个地区的章节成果分别点亮谷地的工匠、海港、药箱和茶席服务台。恢复服务后可以使用既有脱战补给规则，不增加战斗属性。城门居民现在有简易的步行肢体动作。

谷地敲桶、王国木靶、港口酒瓶保留射击成绩；永冬改为循蹄印寻找白马，京都改为跳石／滑翔不湿鞋过河。完成只保存经历和角色反应，不派发伤害奖励。原试炼、宝藏、伪晓回声和涂装继续保留。

## 场景与资源完成项

旗舰甲板在导出的正式运行资源中切开两个真实舱口，船腹补齐地板、舱壁、船肋、双坡梯、栏杆、航图桌、货箱和灯具；没有用传送替代下舱。警报可提前切断，取证后也可通过战斗处理。已解除提督命令的旧档不会因补取记录重新生成追兵。

修院维修通路补上石墙书写小室与书架；京都水门侧路补上纸铺、避难间两间可穿行町屋和独立屋顶连接。拒马采用交叉木桩、金属拉环和倒伏残材，药车补上车辕、木板、车轴和辐条，按实际位移转向和转轮。基地服务、索具绞盘、信号旗、港灯、发射天线与塔顶控制器使用各自造型，并显示完成后的状态。

地图运行资源拆为 `.core.glb` 和 `.visual.glb`。地形、碰撞、互动机关与状态物件常驻，静态大体量美术按地区实际下载，常规最多保留当前及一个临近地区。离开后释放所属网格、材质和索引缓冲；回访重新载入。失败保留进度并提供重试，当前地区画面未就绪时暂停行动，避免在未呈现的地区内继续交战。年代角色按距离加载，离开后释放；当前选择的从者与执行当地支援的拿破仑保持可用。Saber 在远离湖畔且已切换其他从者后也会释放外观。

源地图重新生成后运行 `cd world && npm run build:stream-assets`。这一步重做舱口和资源拆分，不修改原始地图文件。`?eager` 仅保留为完整美术调试／回归入口，正式默认不开启。

## 保存与失败边界

- 只保存已经提交的事实；操作中的持续计时不写入存档。
- 移动、攻击、受伤、失焦、菜单和离开交互范围会中断持续操作；不会将后台经过的时间计入操作。
- 发射器守卫被击败与因离场取消分别处理，取消不能算胜利；离场重试会重新启动未完成遭遇。
- 城门打开后不因战败而关闭，尚未抵达的居民从安全节点重新开始。
- 药车与商船保存沿途检查点；重载从最近检查点继续。港口放行不等同于已经离港，药车出发也不等同于抵达。
- 已提交的永久通路、契约和结尾不会被主动重战清除；新事件不派发可重复刷取的数值奖励。
- 继续复用原有保存错误提示、设置中重试和备份恢复机制。

## 验证方式与边界

最终全量回归 **1,745 项通过、0 失败**；最后的旧档设施显示与交付复核 **16 项通过、0 失败**。类型检查、生产构建和差异格式检查均通过。

本轮最终验证收据与日志见 `world/validation/open-world-alpha/verification.json`。自动流程覆盖实际入口按键、双舱口来回通行、警报处置、居民实体工作、跳石与涉水差异、骑兵真实接触及从者选择保持、资源释放与回访重载、失败重试和迟到下载取消，并继续运行全量历史回归、类型检查和生产构建。

自动主入口流程使用非 GPU 渲染替身，部分长战斗使用测试伤害隔离状态；骑兵接触测试使用实际加载的白马模型和正式冲锋逻辑。另在浏览器检查正式 WebGL 画面，并实际使用备用控制入口行走。鼠标锁定被浏览器拒绝时，可点击「使用拖拽视角进入」，用右键拖拽或方向键转动视角，WASD 行走、左键射击、Esc 暂停。

这些证据不替代陌生玩家的完整试玩。12–15 分钟王城段、首小时与 5–7 小时总时长是设计预算；固定设备上的长时间帧率、声音混音和难度偏好需要实际游玩采样，不能从自动检查推断。
