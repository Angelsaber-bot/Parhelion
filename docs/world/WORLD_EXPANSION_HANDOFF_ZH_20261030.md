# Parhelion World 扩展交接 · 2026-10-30

**范围：**保留幻日谷、落日王国、黑帆、永冬、京都五区框架，在既有角色与武器上扩展路线、战斗、居民互动和技能。本说明随基线 `350f564` 之后的本次源码交付；发布状态以该提交的 GitHub Actions 结果为准。八小时是开发迭代目标，不是新增内容时长承诺。

## 上手与存档

新开局为空手：先按指引访问观测终端，再到枪械工坊武器架领取装备、进入靶场。近战和技能也需先取得装备；签约并召唤从者后，Q/X 使用该从者技能，否则使用探索者技能。

| 操作 | 默认输入 |
|---|---|
| 移动／奔跑／跳跃 | WASD／任一 Shift／空格 |
| 瞄准／射击 | 按住 E 或鼠标右键／鼠标左键 |
| 互动／继续对话 | F |
| 三段近战／闪避 | B（每段后半程再按以接续）／Z（配合方向，无方向时后撤） |
| 战技／终结技 | Q／X |
| 召唤或收回／切换从者 | T／Y |
| 地图／任务指引／返回主线指引 | M／G／P |
| 安全据点旅行 | N |
| 设置／释放鼠标 | O／Esc |
| 重置进度 | R，须确认后才执行；取消不清档 |

设置支持主、副按键及灵敏度、瞄准灵敏度、反转 Y。旧自定义绑定优先保留，冲突的新默认键可能被重新分配，**以设置和 HUD 显示为准**。V/C/数字传送属于调试功能，不应作为普通路线可达性的验收证据。

已有核心完成记录仍有效，不会为了新增章节前置而强制重打。当前 v2 进度优先，仅缺少当前存档时迁移旧 v1。完整重置清除任务、契约、发现、装备和战斗状态，空手返回初始营地，但保留语言、按键、画质等偏好；战败复活则保留装备和进度。若浏览器禁止保存，重置仅在当前会话生效，刷新可能恢复旧进度，界面会提示。不要为体验新增内容先删除自己的存档；需要重置验收时使用独立测试存档。

| 区域 | 主路线与新增选择 |

| 黑帆 | 拿骚见黑胡子 → 操作要塞炮击沉三艘幽灵艇 → 栈桥登舰挑战亡航提督 → 回酒馆立约。炮有独立炮口、转向范围与装填，步枪不能替代。修复归航灯给藏宝图下一条线索，支线碎片不再卡住登舰主路。 |

| 京都 | 三条大桥见武藏 → 破坏三面桔梗旗 → 本能寺主线挑战并回访立约。正面有剑／枪组合；点亮旅籠路灯后，可从南门沿矮坡向西到安静射击点。金阁、清水仍可选，本能寺桥口增加可见木质引坡。 |

四处时代核心恢复后，回幻日谷观测终端可留下**可选**收束记录；文案只回顾实际完成的修复，不补发未做的支线。未完成契约、从者和探索仍可继续。

## 战斗、表现与旅行

- 普通敌人分追击、决斗、破阵、轰击、火枪、长枪等角色；看前摇、避开突刺与冲击范围，利用掩体，注意决斗者第二刀。普通敌人部分前摇可被近战打断，但不能无限硬直；自然收招窗口命中有 Punish 奖励。
- 步枪有远距衰减、八发热循环及自动散热；HUD 显示热量与等待。终结技能量来自玩家枪击／近战造成的实际敌方生命损失，不靠技能或从者伤害自充。切换从者、菜单和旅行不刷新冷却。
- 技能身份各异：探索者「破阵脉冲／曙光反击」，圣剑从者「风王剑波／誓约之光」，黑胡子「破阵枪击／黑帆炮列」，拿破仑「鹰旗突击／帝国铁骑」，武藏「二天双斩／无空连刃」。从者动作绑定现有攻击动画接触事件；骑兵冲锋校验路径，启动失败不扣技能。Boss 可再挑战，首胜奖励不重复领取。
- 新美术主要是运行时制作的修复道具、灯火、技能效果与短标题演出，复用既有人物／武器；不是整套新 AAA 角色模型或预渲染 CG 过场。
- NPC 对话等玩家继续；打开地图、菜单或失去焦点会安全清理。步行到据点入口才能登记旅行点。旅行只到已发现入口，并复查落点净空、落地状态、战斗／追击与脱险五秒条件；游泳、滑翔、飞行、操作炮台、动作中或战败时不可用。生命、装备、进度、能量和冷却不因旅行重置。
- 设置含战斗音效音量／静音及「降低技能闪光」（未手动覆盖时遵循系统减少动态效果偏好）。音效需用户操作后启动，失焦停止。清晰度可即时切换；特效档变更会重载地图并保留已保存进度。高分辨率增加像素开销，不保证高帧率。

## 建议 10–15 分钟抽验清单

这是**建议时间盒**，未经真人计时或通关验证；不是十五分钟完成五区。先抽验基础循环，跨区章节与结局留作后续完整验收，不用调试传送代替步行验证。

- [ ] 用独立测试存档进入新游戏；确认空手、终端 → 武器架 → 靶场顺序成立，领枪前不能造成枪击伤害。
- [ ] 与档案员对话，用 F 继续；开关地图和设置后回到游戏，确认没有卡住或残留射击输入。
- [ ] 到最近合法战斗点，试 B 接段、方向 Z、Q；观察前摇／收招、热量与冷却，检查墙体不能被闪避穿过。X 未充满时不能释放；本轮不强求攒满。
- [ ] 走到据点入口登记，N 查看列表；若已有第二个发现点且脱险五秒，尝试往返，确认生命和冷却未重置。未发现第二点时仅验证列表，不赶路凑时限。
- [ ] 打开 O，试改一个绑定、音量／静音和降低闪光；回到游戏确认提示同步。刷新后核对装备、任务和设置保留。
- [ ] 最后仅在该测试存档按 R：先取消，确认进度不变；再确认重置，检查空手回营地、偏好保留，刷新后不复活旧进度。

后续章节验收重点：黑帆三艇只能由炮击处理；京都安静坡路确实可走可射；永冬炉火余温；王国试炼停战及重赛；四核心后可选记录不吞掉剩余契约。

## 验证边界与开发入口

已有 Node 真 GLB／BVH 碰撞路线、动画接触、战斗状态与存档测试；生产入口也有 **显式无 GPU 渲染器桩** 的 DOM／输入集成检查。这不等同于浏览器画面或真人操作验收。云端浏览器无法创建 WebGL 上下文，因此未完成真实 GPU 生产启动、目标设备 FPS 或视觉接受度验证。

早期无 GPU 快照曾出现京都 CPU 中位耗时 **+19%** 的风险，原始记录保留。随后针对隐藏敌人的矩阵遍历做限定优化，三轮独立对照中的 CPU 代理中位耗时约降低 **54–59%**，实际接入也通过行为回归与同条件确认。此结果不是 GPU 或目标设备 FPS，不能据此宣布此前 27–40 FPS 问题已解决。详见 [原始对比](WORLD_EXPANSION_CPU_COMPARISON_20261030.md) 与 [优化跟进验证](WORLD_CPU_VISIBILITY_FOLLOWUP_20261030.md)。
