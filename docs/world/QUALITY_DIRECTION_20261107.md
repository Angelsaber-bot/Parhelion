# Parhelion 下一阶段质量方向

本文件记录开发取舍，不代表内容已全部交付。现有工作区包含此前的目录重组，本轮不回退或重写这些成果。

当前范围以用户后续指示为准：仅精修幻日谷、拿破仑、黑胡子、亚瑟王与宫本武藏五张已有地图。停止新增地图和章节；已撤销区域的原型、素材及备份均不保留。

## 判断

目前最值得投入的是让已有系统互相支撑，而非增加同构清单。已有五区主线、居民工作、探索与可选调查足够多；应先解决旧档卡点、目标难找、地图设施缺乏结构和切区资源生命周期问题。

对现有内容的改动必须回答三个问题：具体改善了哪种玩家行动；地形如何支持这件事；改动后如何验证游玩结果。没有答案的改动不进入制作。

## 对标的可执行标准

- 地区移动方式与地貌一起设计。参考 HoYoverse 开发者对纳塔 5.2 新地区与空中能力的介绍，取其“探索能力与地形相配”的原则，不复制角色、建筑或视觉符号。[开发者介绍](https://blog.playstation.com/2024/11/10/20241111-genshinimpact/)
- 战斗信息服务玩家当下判断。参考 Housemarque 对 Returnal 的界面和多通道反馈说明，重点是让弹药、危险和能力就绪容易识别；不照搬其全部特效或硬件机制。[UI/UX 开发说明](https://blog.playstation.com/2021/05/11/unpacking-returnals-ux-design-gameplay-first-ui-retro-futuristic-tech-and-accessibility/)
- 武器差异来自行为与可读反馈；外观奖励不掺入数值优势。参考 Returnal 开发者对武器行为组合的描述，Parhelion 仍需自己的射击测试与平衡目标。[战斗开发说明](https://blog.playstation.com/2021/01/13/returnal-combat-details-upgradable-weapons-otherworldly-tools-and-risky-buffs/)

这些是设计参照，不是宣称已达到同等品质。自动测试、浏览器截图与真实长时间试玩分别验收，不能相互替代。

## 当前制作批次

1. 旧档京都/永冬章节衔接：利用已经赢得的结果，仍要求新的真实取证、清路和运输。
2. 任务日志：组合检索、结果数量、中文输入法和焦点修正；可选调查与人物主线明确区分。
3. 地区流式资源：取消、失败、重试和正常释放使用同一所有权规则，不销毁共享描边。
4. 视差庭院：在幻日观测所南侧制作一个实际可步行的小场景。前/侧观察真实双环、显式选择解释、保留记录。无武器门槛，无计时，无重复战斗。
5. 庭院美术：观察位、铺地、支架、刻度和记录板组成可信的现代观测装置；完整的往返通行与清草范围接受真实地图碰撞测试。
6. 原创“折光测绘”涂装：与庭院记录关联的纯外观奖励，保留旧偏好，允许旧档补玩。

## 当前范围（用户后续明确）

仅打磨现有五区：幻日谷、拿破仑、黑胡子、亚瑟王与宫本武藏。不制作新地图或新章节，不保留此次被撤销的新区域原型、素材或备份。

后续投入已有地图的建模、地形与室内通行、枪械反馈、运行性能、存档衔接和现有历史剧情连贯性。历史时代及现行人物篇是内容约束，不以架空的新背景替代。
