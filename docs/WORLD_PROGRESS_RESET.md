# World 新开局与重置（云端验收）

- 正常无存档开局与完整重置均从 Alpha 初始营地 `spawn_p1` 出发，主角空手。曙光 AR 的唯一持有条件为完成现有 `armory_rack` 互动；隐藏枪、持枪 IK、肩射缩放、射线伤害、机关命中与弹道特效使用同一持有状态。
- 原教学顺序保留：观测终端 → 枪械工坊武器架 → 靶场。领取装备前不要求射击；已有真实碰撞路线测试覆盖营地走到终端、武器架和靶场。领取时清除先前按住的扳机／瞄准输入，避免自动开枪。
- 重置清空任务、发现、武器持有、契约／选中从者、Boss 完成状态与战斗瞬态；取消待触发从者攻击，关闭飞行／滑翔／肩射，恢复体温、生命和默认朝向，归零速度与物理积累，并立即回到初始营地。门与目标按空进度重新应用，设置、语言、按键、灵敏度、画质、HUD 偏好和从者外观不删除。
- 当前 `parhelion.world.progress.v2`（包括空重置快照）始终优先于旧 v1 存档。仅缺少当前存档时迁移旧区域进度；成功写入当前快照后才移除两项旧进度键，防止重载复活旧任务。读写受限时仍可在内存中重置，但提示刷新可能恢复旧进度，不声称已经持久保存。
- 主动输入的 `?region=…`、`?spawn=…`、`?cam=…` 仍可用于新开的调试页。执行完整重置后仅移除这些起点覆盖及授予任务的 `lit` 参数（`history.replaceState`，不刷新／跳转），保留其余参数和 hash，避免刷新又回到调试章节。完整重置同时恢复第三人称。
- 战败复活与完整重置不同：战败保留已获得的装备、任务和契约；完整重置后，后续战败的安全出生点也改为初始营地。

## 验证

`world/validation/progress-reset.test.ts` 直接执行生产启动、重置、互动、ADS 与世界状态应用函数，使用真实进度／契约／Player／Animator，以及隔离的内存存储。覆盖脏进度→重置→重载、旧存档复活、空手开局、选中武器残值、异步武器加载、设置保存、调试 URL 清理、持有输入、从者待触发攻击与门重新上锁。

`shooting-integration.test.ts` 验证空手无伤害、任务命中或弹道；`shooting-free-look.test.ts` 保留已装备枪的正常射击和奔跑低持枪首发流程。`world-smoke.test.ts` 使用实际 GLB 碰撞验证重置后落在原营地平台；`hub.test.ts` 验证既有领取装备路线。

这些为源码／模型／物理测试，不等同于真实浏览器 WebGL 视觉操作验收。测试没有读取或删除真实用户存档；本轮没有推送或发布。
