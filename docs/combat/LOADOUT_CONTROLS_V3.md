# 自选双枪＋近战 / 双开镜键（规则 v3）

基线：`8ecf30046e7c950cf2d8855e7f6cda41f120d2ad`，开始前从 GitHub fetch 核对。独立云端 worktree 实现，未覆盖其他工作区、未访问用户电脑。本文是当前功能说明；`WEAPON_INTEGRATION.md` 保留上一轮历史。

## 用户可见变化

- Arena 大厅选两把**不同**枪械＋一件近战，自动保存在当前浏览器；枪槽 1/2、近战槽 3，滚轮仅循环这三个槽。原有枪械皮肤保持按武器目录编号保存。全部八件模型都是真正可用的战斗装备，不是仅展柜。
- 默认按住 **E 或鼠标右键**开镜；同时按住时松开任意一个仍持续。主／副键可分别修改、清空副键或显式交换冲突键。切枪、死亡、装填、菜单、失焦等继续清除旧开镜输入。
- World 默认 **F 互动**。按用户最后澄清，**删除手动飞行上升／下降**，没有把它改成新的垂直飞行能力。Space 跳跃／空中滑翔、游泳出水及上升气流保留。原调试飞行保留为 V 水平移动（非滑翔），不再根据抬头或旧 `up` 参数改变高度；HUD 明确显示当前模式。
- 原“升降没效果”的代码原因：旧 `input.up` 只在 `player.flying` 调试分支消费，普通跳跃、滑翔不消费它；原设置将 E 互动／上升混写。最终按用户更正删除该控制，而不是修复启用它。
- 设置 v2 会读取 v1：保留自定义键及灵敏度，只迁移旧默认 E/F；被自定义占用的新默认另找空键并弹出解释，不静默重置整套设置。旧 v1 原始记录保留。所有操作提示来自实际映射。

SMG 有更明显距离衰减；狙击移动散布较高、慢射速与慢装填，头部倍率 1.7。Arena 维持 FPS，DMR FOV 24°、狙击 FOV 16°，两者有无遮挡镜内视野；近战不缩放。World 维持 TPS，不新增角色、故事或近战任务。

近战按一次左键启动一次，不能按住自动连砍；没有弹药或换弹。命中只在权威服务器前摇结束后计算：以起手方向锁定三维角度、当前目标位置（不回溯）、距离和墙体／敌方护盾遮挡，最多命中最近一个敌人、不爆头、不穿墙。换武器／死亡取消未落下的攻击，切来切去不能取消冷却；服务器时钟保证输入积压批处理不能压缩前摇。远端角色与第一人称武器有区别化蓄势／挥击姿态和声音；这些是现有静态节点程序动画，不声称新骨骼动画。

## 权威与资源

`shared/content.ts` 白名单只允许 `[GunId, GunId, MeleeId]`，两枪必须不同；缺省可用公开默认装备，不信任客户端“解锁”字段。输入只选择 0/1/2 槽位，无法传目录编号直接拿未选武器。非法配装在挤出 Bot 前拒绝。离线 Session、Match、Bot、Colyseus 和 Worker RoomCore 使用同一规则。

协议升级 **v3**：旧 v2 客户端明确拒绝，新客户端也拒绝旧服务器握手。发布必须更新 Worker 与静态客户端整套，不能只发布 dist；见 `DEPLOYMENT_HANDOFF.md`。

八个原始 GLB 字节不变；只更新 registry 中新增五件的战斗映射与握把／瞄具坐标。实际 GLTFLoader 检查 271,476 三角形、PBR、命名分件、双实例资源释放；五枪瞄具居中／枪口在屏、三近战多个姿态无眼后裁切。模型失败时保留对应枪或近战的可用程序几何；懒加载与释放路径不变。
