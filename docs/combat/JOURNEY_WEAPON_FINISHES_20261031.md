# Journey weapon finishes

Five visual-only finishes accompany the optional resident chronicles: Radio Echo (Valley), Remembered Oath (Britain), Homeward Tide (Black Sail), Winter Ember (Winter), and Paper Lantern (Kyoto). Original restores the authored Dawn rifle/Refract Blade palette. Unlocks use the corresponding `campaign_<region>_complete` progress flag; the cosmetic store never creates these flags.

The settings control displays locked entries and explains their story source. Preferences use the isolated `parhelion.world.weapon.finish.v1` key. New-game/imported saves without an unlock render Original without deleting the preference; earning the flag again restores it. Denied storage retains an in-memory selection with an honest status message.

The actual authored weapon geometry, muzzle and hand anchors, hitboxes, original source textures, transparency, roughness, metalness, emissive strengths, weapon statistics, controls and Arena loadout/network state are unchanged. Earned rifle appearances add private 128×128 albedo maps to originally untextured ivory/dark panels: radio pinstripes, oath cross-bands, tidal waves, frost lattice and lantern slashes. Original restores its exact original color and map references. The rifle controller caches at most ten maps (640 KiB source pixels, plus renderer mip overhead), with no per-switch allocation or added draw calls. Material clones are private to each loaded weapon; disposal restores material ownership and releases each clone once. Selections made before an asynchronous model load are applied when that model becomes ready; late loads cannot reattach after cancellation.

Automated validation includes actual AR and blade material/geometry invariants, suffixed blade material names, pre-load selection, reversible changes, repeated disposal, denied/malformed storage, a real JSDOM control cycle, lock bypass attempts, language changes, new-game fallback, and current main progress/input tests. Same-camera offline CPU previews are in `artifacts/weapon-finish-final-renders/`, with Original and all five earned choices for both weapons. These use actual runtime meshes/material colors/UVs; they are not browser/WebGL, FPS, or UI screenshot evidence. Root review found that blade UV islands stretched the experimental accents into soft patches; those blade patterns were removed. The shipped blade uses clean region palettes and unchanged authored label details. Rifle accents remain restrained, not a continuous custom decal wrap.

Locked, earned, and reset-with-retained-preference actual-main DOM snapshots and option-state JSON are under `artifacts/weapon-finish-ui/`. They explicitly label synthetic save fixtures and absent WebGL; they are not gameplay screenshots. The earned fixture has all six choices, while locked/reset have only Original; reset preserves the Oath preference without rendering it.

## Positive-application correction: mixed Three module hosts

A later independent audit found the non-GPU actual-main fixture's GLTF loader can supply objects from a different Three constructor. The original `instanceof Mesh` / `MeshStandardMaterial` checks then selected an earned finish ID without applying any private material changes. This did not invalidate earlier direct native-asset preview sheets or gameplay-neutrality checks, but **old actual-main selected-ID evidence alone did not prove visible appearance application**. The browser single-module path was not demonstrated broken.

The controller now uses structural Three brands plus defensive shape checks: valid mesh geometry/material ownership, material clone/dispose methods, PBR color brand and methods, and null/texture albedo map. A PBR flag by itself is insufficient. Cross-constructor regression requires a real private pattern/color change, exact original restoration and no source mutation. Two equipped instances sharing one original material must own separate clones/patterns; disposing one cannot dispose or reset the other. Malformed PBR color/map shapes are not recolored.

Independent actual-main earned/locked/reset appearance assertions are separate from the original neutrality test. No new skins, geometry, statistics, unlock conditions or selection semantics were added by this correction.
