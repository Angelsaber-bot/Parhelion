# M 完整地图：关键导航点位

这次修改的是按 M 打开的完整地图，不是角落小地图。

- 移除普通互动、发现、出生、静态及实时敌人圆点；保留玩家白色方向箭头、金色当前任务。
- 五个地区标题 + 最多五个既有关键目的地、四个既有章节入口。统一低饱和符号；入口横杠表示仍受既有 `summon_circle` 条件锁定。没有新增传送操作或权限，也不改变按键、任务、碰撞、资产和存档。
- 区域名称优先，关键地点名按空间避让；小屏省略次级地点名，优先保留五地区名称；极窄拥挤布局允许省略标题而不遮挡当前目标。按 CSS 显示尺寸缩放，而不是只按固定 1200px backing canvas 缩放。
- 当前任务优先于次级符号，抵达目标仍保留金色外轮廓；世界内坐标投影不改，世界外调试目标留在边缘。
- 完整地图层级置于帮助 HUD 之上，关闭后原 HUD 状态不变。角落小地图绘制流保持一致。
