# 四款原创枪械新外形

保留清理后的 12 款精选设计，再加入四个主题、轮廓各不相同的新模型，合计 16 款。它们不是同一套系列在不同武器上的套用。

| 武器 | 设计 | 主要造型与细节 |
| --- | --- | --- |
| AR | 引力熔环 | 分体陶瓷导轨围住悬置核心，三轴金属环形成镂空机匣；核心有缓慢的层流，护甲有嵌缝、散热槽和螺钉。 |
| SMG | 游鲤 | 紧凑的锦鲤瓷甲，真实厚度的鳍尾、珊瑚色斑、沿曲面排布的立体鳞片，仍保留双握持与可拆弹匣。 |
| DMR | 夜枭圣咏 | 黑曜翼甲叠在银色羽片上，切面石榴红枭眼、尖眉骨、完整双支点镜座和细长枪管构成精确步枪身份。 |
| 狙击枪 | 时序之钥 | 胡桃木色机身开出机械窗，带黄铜齿轮、真实厚度的珐琅钟盘与刻度；长枪管有细弧护架，镜身保持贯通。 |

## 研究依据

研究了 Riot 的[皮肤制作流程](https://playvalorant.com/en-us/news/dev/the-craft-and-fantasy-of-valorant-weapon-skins/)、[Spline 的美术与工程配合](https://playvalorant.com/en-us/news/dev/artists-engineers-and-the-tech-behind-spline/)、[武器视觉识别原则](https://playvalorant.com/en-us/news/dev/how-the-valorant-arsenal-was-built/)，以及 Valve 的[工坊设计指南](https://www.counter-strike.net/workshop/workshopstyleguide/)。

用于本次原创实现的判断：主题先落实到结构和材质；控制大、中、小细节的层级；在持枪、瞄准和侧视中检查；让材料有明暗余量；特效范围局限于核心，避免依靠整枪高亮。没有复制参考作品的模型、图案、名称或整套系列。

## 实现与边界

完整几何由原生 Three.js 构造，部件内按材质合批。倒角、环架、鳞片、翼甲、钟盘和齿轮均为实际几何；核心层流是轻量材质效果。导出 GLB 使用同一构造器，可编辑文件和尺寸／套接点清单位于 `assets/weapons/structural_v1/`。

四款直接接入工坊、第一人称、远端持枪显示和原有弹匣／枪机动作。枪口、瞄准点、握持点、伤害、射程、射击节奏与命中规则保持一致；没有新增音效、终结动画或付费机制。

切换不同结构时，工坊保留观察方向与相对缩放，但按新轮廓重新适配画面；复位视角恢复该结构的初始展示。

回归覆盖八个完整替换模型：导出一致性、独立资源和释放、真实轮廓差异、原枪口和瞄准点、贯通的瞄准通道、第一人称近裁切以及近战动作。存档改用稳定皮肤 ID，旧索引迁移仍只识别保留下来的原款式。浏览器与联机验证保持静音。
