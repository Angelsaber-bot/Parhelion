## 工坊与保存

工坊只显示保留款式，撤掉「经典涂装」入口。卡片按该武器实际款数排版，保持「新外形」「已装备」、旋转预览和复位视角。预览不自动装备。

持久化改为以武器 ID 映射皮肤 ID 的 `arena-lobby.skinIds`；读取旧 `skins` 数字数组时，只转换仍然存在的身份。被删或无效的选择回到对应武器的第一款精选皮肤，保留其他大厅字段。新记录不再写入旧数字数组。

压缩目录后，网络中同一个数字代表的身份可能改变。客户端与服务器版本同步升到 9，旧版 8 客户端需刷新，避免联机中误显示另一款皮肤。武器伤害、射程、攻击节奏、握持锚点与命中规则没有修改。

## 模型与验证

四个独立结构保留：兽颚霰弹枪、水晶蝶翼剑、竹节长枪、圆筒糖霜战锤。模型直接按需构造，跳过原枪体下载；可编辑导出与套接点清单位于 `assets/weapons/structural_v1/`。

绘纹皮肤仍通过表面投影裁掉跨孔洞、悬浮片段，按材质合批并随实例释放。验证覆盖存档迁移与重新保存、实际大厅／工坊保存路径、精简目录、实例资源释放、四个模型的套接点和近战动作、联网版本拒绝，以及皮肤不改变战斗规则。

所有浏览器验证使用 `?mute` 或 `?test&mute`。普通游玩声音保持原设置。原始设计参考见 [首批独占皮肤说明](./WEAPON_EXCLUSIVES_20261102.md)。
