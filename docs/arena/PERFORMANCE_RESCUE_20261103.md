# Arena 流畅度修复

修正上一轮默认启用的 2× 分辨率、4× 多重采样 HDR 和全套后期组合。皮肤几何、近景材质与持枪灯光保留。

- 默认流畅模式：1 CSS 像素对应 1 绘制像素，直接抗锯齿输出，关闭整屏后期与阴影。
- 可选精致模式：最高 1.25×、超采样预算二百万像素；HDR 使用单采样，FXAA 处理边缘，避免与多重采样叠加。
- 画质保存使用 v2 键，旧版自动选择的高负载偏好不会延续；用户在新版显式选择后正常保存。
- 工坊、设置或隐藏页面覆盖地图时不提交世界渲染。大厅限帧、暂停画面限帧，工坊预览最多 30 FPS、最高 1.25×。
- 即时改画质同步重建装饰及战斗特效预算，释放旧实例；流畅模式环境粒子为原预算 35%。对局规则及命中保持一致。

`?perf&test&mute` 提供仅用于验证的帧率、P95 帧间隔和 CPU 提交耗时读数；普通入口不创建该面板。只衡量浏览器实际提交的画面，不把规则测试通过视为流畅度证据。基线为隔离的上一版提交，仅添加同一性能读数代码；每次保留一个测试页面，使用相同 1280×720 视口、ASTER、2v2 和配装，在预热后读取最近 240 帧。初步稳定读数：上一版 30.6 FPS／P95 35.5 ms，新版流畅约 59–60 FPS／P95 18 ms。数据只代表该机器、场景及测试窗口，其他地图及长时间战斗另行检查。
