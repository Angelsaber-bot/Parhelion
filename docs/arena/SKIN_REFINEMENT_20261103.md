# 皮肤精修与清晰度

后续性能修复已调整下述初版画质预算与默认设置，当前策略见 `PERFORMANCE_RESCUE_20261103.md`。

16 款现存皮肤全部接入同一套近距离材质细节，分别表现珐琅、瓷釉、金属、树脂、织物、竹纤维、晶体、糖霜及木材。表面粗糙度、微法线和清漆按材料控制，细节随屏幕尺寸过滤，避免远处闪烁；不新增纹理下载。

八个独立外形补充真实几何：更圆滑的环架、保留硬边的倒角、镜圈滚花、枪顶嵌条、鳍骨、握柄细肋或交叉编绳、晶刃与竹叶刃口。其余八款补充投射到真实顶面的主题纹样，优先照顾持枪能看到的枪顶与后部。模型使用同一构造器重新导出，保留机械节点与注册套接点。

工坊和第一人称共用四盏展示灯及独立武器曝光。地图曝光仍按各自氛围变化。持枪腰射角度略向内转并拉远，窄画面进一步居中；瞄准仍沿原始瞄准套接点对齐。伤害、射速、弹匣、命中与联机目录均未变化。

移除按帧耗时悄悄降低分辨率的逻辑。设置新增简短的“画质：清晰／流畅”，即时生效并独立保存，不覆盖配装。清晰模式最高 2 倍像素比，抗锯齿、阴影及后期；流畅模式使用 1 倍并关闭后期、阴影。超采样受六百万像素预算约束，两种模式都不主动降到 CSS 像素以下。旧 `?low` 链接仍选择流畅，在设置改成清晰会移除该参数，保留静音参数。

验证覆盖全部 16 款第一人称 GPU 画面、模型和导出一致性、材质着色器组合、资源释放、瞄准与动作，以及设置即时切换和存档。静音浏览器实测 1280×720 视口在清晰模式获得 2560×1440 绘制缓冲；旧公网低画质在该设备为 1280×720。旧代码允许降至 0.75 倍，但本次基线没有在该设备复现该下限。
