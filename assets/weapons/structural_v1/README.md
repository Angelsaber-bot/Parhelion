# 武器新外形

八个 GLB 是 `arena-game/src/signatureModels.ts` 和 `arena-game/src/signatureGunModels.ts` 使用同一构造器导出的原创模型，可在 Blender 等支持 glTF 的软件中打开编辑。运行时按选择直接构造这些模型，不需要再下载原枪体 GLB；导出文件用于美术编辑和核对。

- 深渊巨口：仿生机匣、双颚齿列、随泵动护木平移的下颚。
- 琉光蝶刃：实心切面晶刃、立体蝶翼护手、紫晶握柄。
- 玄竹：分节长柄、叶形双刃枪尖、古铜竹节束箍。
- 糖霜重击：圆筒双面锤头、奶油旋纹、糖纸束结。
- 引力熔环：分体陶瓷导轨、三轴环、分层紫晶核心。
- 游鲤：瓷甲、立体鳍尾、贴合曲面的叠鳞。
- 夜枭圣咏：银骨翼甲、切面石榴红枭眼、完整连接的镜座。
- 时序之钥：镂空机械窗、黄铜齿轮、立体珐琅钟盘。

统一使用原注册表的 `+X` 前向、`+Y` 向上坐标。各自的握持点、枪口、瞄准点与辅助握持点在 `manifest.json` 中保留。机械部件为独立刚性节点，运行时沿原有时间点播放动作；不含新的骨骼蒙皮、音效或杀敌终结动画。

几何在每个机械节点内按材质合批，并合并重复顶点。每个运行实例独立持有并释放自己的材质与几何，不改动原始武器文件或命中规则。

重新导出：在仓库根目录执行 `arena-game/node_modules/.bin/tsx arena-game/tools/export-signature-models.ts`。

引力核心的缓慢层流在运行时使用轻量材质着色器，导出的 GLB 保留静态材质与几何，不包含浏览器专用着色器。
