# 宫本武藏：参照图重建模型

**这不是官方模型提取，也不能称为“原封不动”。** 已按指定图重建发型、蓝紫色短和服、红金腰带、长手套、长靴和双刀；脸部、发束、领口仍有风格化差异，图中未展示的背面结构包含推定。请结合真实模型渲染判断是否接受相似度。

## 文件
- `Musashi_Editable.blend`：可编辑部件、打包贴图、骨架、4个动作、56个脸部形态键。
- `Musashi_Runtime.glb`：默认完整细节版本，173,648三角面。
- `Musashi_Runtime_LOD1.glb`：明确可选的85,377面版本；脸部几何和56个形态键与完整版相同，不自动替换完整版。
- `Musashi_Reference_Presentation.blend`：可编辑的肩扛刀/低位持刀展示姿态。
- `Musashi_ReferencePose.glb`：已烘焙姿态的静态展示模型，不是游戏动画主文件。
- `renders/`：真实三维模型、动作样帧及GLB重新导入后的渲染。

## 游戏接入
GLB为米制，头顶约1.67米（发束更高），+Y向上、+Z朝前。载入后播放`Idle`；绑定姿态为T姿态。`Idle` 3秒、`Walk` 1.0667秒、`Run` 0.6667秒循环；`Attack` 1.6秒双刀连击、不循环、结束回待机。均为原地动作，行走/跑步名义前进速度分别为0.7488、2.0016米/秒。命中事件为30fps下第20、34帧（第1帧对应0秒）。

左右握把节点：`Attachment_LeftHand_Katana`、`Attachment_RightHand_Katana`。65根骨骼、每顶点最多4个归一化权重。衣物和头发为蒙皮，不是布料/毛发物理模拟。

## 已验证与限制
实际GLB通过Three.js CPU变形、动作循环、6组动作混合、全部56个脸部形态键及握把跟随检查；也已在Blender重新导入GLB并渲染。**没有声称通过浏览器/GPU实测。** 任意新动作、极端姿势或后续物理模拟不能据此保证不穿模。
