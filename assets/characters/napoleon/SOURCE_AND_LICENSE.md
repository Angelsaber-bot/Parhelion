# Source provenance and rights scope

## Human anatomy foundation

- Official Blender Studio Human Base Meshes bundle v1.4.1.
- Official download: https://download.blender.org/demo/asset-bundles/human-base-meshes/human-base-meshes-bundle-v1.4.1.zip
- Selected asset: `GEO-body_male_realistic` and its supplied eyes; asset metadata credits **Dan Ulrich** and declares **CC0**. The official bundle README dedicates the supplied base assets to CC0.
- Selected geometry only was imported, with script execution disabled. No unrelated bundled rig or third-party license text was imported as authority for this asset.
- Anatomy was reshaped; the face, red hair, clothing, cavalry saber, mounted pose, skin integration and rider animation were authored for this project. Shared project rig/weight infrastructure was adapted, not a game-ripped character mesh.

## Horse anatomy and texture foundation

- **Lyndon Daniels / lyndon**, “Realtime Rancher's 3D Model Pack,” OpenGameArt, 2012.
- Source page and CC0 declaration: https://opengameart.org/content/realtime-ranchers-3d-model-pack
- Original source download: https://opengameart.org/sites/default/files/horse.zip
- The original authored horse OBJ and texture set were inspected and adapted: real-world scale, raised head/neck, white coat and mane/tail textures, saddlecloth, saddle/tack, skeleton, skin weights and original animations.
- CC0 1.0 reference: https://creativecommons.org/publicdomain/zero/1.0/
- Courtesy attribution is retained even though CC0 does not require attribution.

## Project-authored work and character reference

The user supplied an FGO Napoleon illustration as the visual reference and requested the same core identity with a saber, white horse and cavalry presentation inspired by the familiar Napoleon Crossing the Alps composition. No FGO game mesh, texture or animation was copied or extracted.

CC0 provenance of the anatomy foundations does **not** grant rights to the FGO character identity or imply official affiliation. This is a derivative fan interpretation. Character/IP rights remain with their respective owners; this file does not claim commercial character clearance or dedicate the entire resulting character to CC0. Project-authored contributions follow the repository's applicable license/permissions rather than acquiring a new blanket license from this provenance file.

The reference screenshot and downloaded source archives are deliberately excluded from the public asset whitelist. The editable Blender deliverable contains the adapted geometry and packed textures needed to use and edit the model.
