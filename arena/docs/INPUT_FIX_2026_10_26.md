# 方向键锁死 / 自动滑行修复

日期：2026-10-26 UTC。基线为完整 0.3.0 美术版；美术/地图版本保持不变。

## 原因与修复

原版将每次 `keydown`（包括自动重复）写入全局 Set，仅在 `keyup` 或窗口 `blur` 清除。指针锁、标签页/页面生命周期、俯视和出生点切换没有统一清理；即使 blur 已清空，随后到达的重复 keydown 也会重新写回旧方向。自动巡检还会在失焦后继续走，造成类似“按键锁死”的效果。

新增 `runtime/input.js`，统一处理：

- WASD 与上下左右同时按住/释放，保留独立按键状态；正常长按不会过期。
- 仅新按下的非 repeat 事件可以激活按键；失焦、隐藏、指针锁变化/错误、Esc、系统快捷键、页面恢复、窗口/全屏变化、菜单或 UI 焦点都清空输入。
- 每帧检查文档焦点与可见性；漏发事件时仍停止输入。连续帧间隔超过 1 秒也清空，避免嵌入宿主休眠后的旧输入残留。
- 俯视、出生点切换不带入旧按键。表单、下拉框、按钮和可编辑文本使用原生键盘行为，不驱动玩家或触发游戏快捷键。
- 捕获阶段的子元素 blur 不冒充窗口 blur；场景可聚焦，出生按钮完成后恢复场景键盘焦点。
- 无指针锁 API、同步失败与 Promise 拒绝都安全降级；仍可使用 WASD/方向键。已锁定场景的普通点击不打断合法长按。
- 自动巡检在输入中断时暂停，必须重新点击启动；正常巡检与 WASD 手动接管保留。

切回窗口/模式后请松开再按方向键。未增加移动惯性或长按超时，未修改 `physics.js`、地图、步速、转向速度、斜向归一化、重力、坡道、出生布局或任何模型资产。

## 可重复验证

在 `arena/` 内执行：

```sh
sh validation/run_checks.sh
```

仅需 Node.js 18+ 和 Python 3，无第三方测试包，无联网依赖。

| --- | --- |
| JS 语法检查 | app.js / input.js 通过 |
| 输入单元测试 | 37/37 通过 |
| 实际 app.js + Three.js + GLB + 物理的集成检查 | 45/45 通过 |
| 原版运行同一组集成断言 | 15 通过，30 失败（预期的对照证据） |
| 地图基础检查 | 48/48；10 条正反路线 |
| 扩展移动检查 | 164/164；30 个边缘案例、92 个转角、14,330 节点连通 |

| 细节净空检查 | 3,129 个路线采样，0 装饰交叉；使用保留的模型边界数据 |

集成测试实际运行完整 app 的初始化、GLB 解析、场景建立、动画循环和物理；DOM 生命周期事件、时钟与 WebGLRenderer 是测试替身。它验证状态和坐标，不验证真实浏览器事件派发或 GPU 渲染。`input_baseline_report.json` 与 `input_integration_report.json` 分别保留原版/修复版结果。原版可通过设置 `ARENA_RUNTIME` 指向其 `runtime/`，再运行 `node validation/input_integration.cjs` 复现（应退出非零）。`INPUT_REPORT` 可指定报告输出位置。
